# 第24章 日本語の文体を制御する — 視点・時制・語尾・会話文・改行ルール、後処理での整形

第23章では、文体の見本を見せて、書きぶりをまねさせました。見本は、文のリズムや語り口といった「雰囲気」を伝えるのには向いています。しかし、「必ず守ってほしい規則」を守らせるのには向いていません。

日本語の小説には、書き方の規則がたくさんあります。三人称で書くと決めたら、地の文に「私は」が出てきてはいけません。だ・である調の地の文に、「〜ました。」が混ざってもいけません。記号にも慣習があり、三点リーダーは「……」と2つ続けて書き、感嘆符のあとに文が続くときは全角の空白を入れます。台詞の閉じかっこの前には、句点を打たない（「〜。」ではなく「〜」）のが一般的です。

ローカルLLMの出力は、こうした規則をよく破ります。「...」や「!」のような半角の記号を使う、台詞に句点を付ける、長い文の途中で一人称の心の声が地の文に混ざる、などです。見本やプロンプトで伝えても、完全には防げません。

この章では、規則を次の3つの方法で守らせます。

1. **プロンプトで指示する**：人称・時制・語尾など、文を書くときに決まるもの
2. **後処理で整える**：記号の書き方、台詞の句点と改行、字下げなど、プログラムで確実に直せるもの
3. **検査して、LLMに直させる**：一人称の混入や語尾の混在など、見つけることはできても、直すには文を書き換える必要があるもの

この章で作るものは次のとおりです。

| ファイル・コマンド | 内容 |
|---|---|
| `src/novelist/rules.py` | 本文を規則に沿って整える・規則を守れていない箇所を探す |
| `prompts/_parts/rules.md` | 規則を、本文を書くプロンプトに書き出す部品 |
| `src/novelist/graph/nodes/rules.py` | 書いたシーンを検査し、違反を直させるノード |
| `novelist lint` | 書いたシーンを検査する。`--fix` で整形する |
| `novelist write --rules` | 規則を検査しながら書く |

## 24.1 日本語の小説の書き方の規則

### 規則の一覧

この章で扱う規則は、次のとおりです。

| 規則 | 例 | 守らせ方 |
|---|---|---|
| 人称 | 三人称なら、地の文に「私は」「僕は」を使わない | 指示 ＋ 検査 |
| 時制 | 過去形（「〜た。」）を基調にする | 指示 ＋ 検査（参考） |
| 語尾 | だ・である調の地の文に、「〜です。」「〜ました。」を混ぜない | 指示 ＋ 検査 |
| 文末の単調さ | 「〜た。」を5文も6文も続けない | 指示 ＋ 検査 |
| 文と段落の長さ | 一文は100字、段落は300字まで | 指示 ＋ 検査 |
| 台詞の句点 | 「行きます。」ではなく「行きます」 | 整形 |
| 台詞の改行 | 台詞は段落の頭から始める | 整形 |
| 字下げ・空行 | 段落の頭を1字下げる、段落の間に空行を入れる | 整形 |
| 記号 | 「……」「――」は2つ続ける。「！」「？」は全角で、あとに文が続くなら全角の空白を入れる | 整形 |

整形する規則は、**プロンプトには書きません**。記号の書き方や字下げを細かく指示すると、プロンプトが長くなるうえに、LLMの注意がそちらに向いて、肝心の本文がおろそかになります。プログラムで確実に直せることは、プログラムに任せます。これは、第14章で文字数の配分をプログラムで行ったのと同じ考え方です。

### 規則は設定で選ぶ

字下げや空行、台詞の句点は、「正しい書き方」が1つに決まっているわけではありません。紙の本では段落の頭を1字下げるのが普通ですが、Web小説では字下げをせず、段落の間に空行を入れることが多くあります。台詞の句点も、古い作品や児童書では「〜。」と打つことがあります。

そこで、規則はすべて設定ファイルで選べるようにします。既定値は、次のようにします。

- 三人称・過去形・だ・である調
- 台詞の句点は打たない。台詞は段落の頭から始める
- 字下げも空行も入れない（原稿として扱いやすく、第15章からの本文とも同じ形）
- 記号の書き方はそろえる

一人称の作品を書くときや、Web小説の形で書き出したいときは、設定を変えます。文体（第23章）ごとに規則を変えることもできます。

### 見つけるのはプログラム、直すのはLLM

一人称の混入や、語尾の混在は、プログラムで見つけられます。しかし、プログラムで直すことはできません。「私は窓の外を見た。」を三人称に直すには、視点人物の名前を入れるのか、「彼は」にするのか、そもそも主語を省くのかを、文脈を読んで決める必要があるからです。

そこで、第21章の一貫性チェックと同じ形にします。プログラムが違反を見つけ、その箇所を引用した指摘を作り、第16章の推敲のプロンプトで、LLMに直させます。第16章と第21章では、LLMが見つけた指摘の引用をプログラムで確かめましたが、この章の指摘はプログラムが本文から切り出すので、引用は必ず本文にあります。

## 24.3 後処理で整える

規則を扱うモジュールを作ります。前半が整形（`normalize`）、後半が検査（`lint`）です。

**`src/novelist/rules.py`**（新規）

```python
"""日本語の文章の規則を、後処理で整え、守れていないところを探す（第24章）。

規則は2種類に分けて扱う。
- 整形（normalize）: プログラムで確実に直せるもの。記号の書き方、台詞の句点と改行、字下げなど
- 検査（lint）: 見つけられるが、直すには文を書き換える必要があるもの。人称・語尾・文の長さなど
"""

import math
import re
from collections import Counter
from dataclasses import dataclass
from typing import Literal

from pydantic import ValidationError

from novelist.config import RulesConfig
from novelist.schemas.review import Criterion, Issue

OPEN = "「『（"
CLOSE = "」』）"
ENDS = "。！？"
QUOTE_CHARS = 40  # 検査の結果に引用する、文の長さの上限
MAX_ISSUES = 8  # 1回の修正で直させる違反の数の上限

# 一人称の代名詞（漢字の熟語の一部、「私鉄」「公僕」などは除くため、直後に助詞を求める）
FIRST_PERSON = ["わたくし", "わたし", "あたし", "ぼく", "おれ", "私", "僕", "俺"]
PARTICLES = "は|が|の|を|に|も|と|へ|には|だって|なら"
POLITE_END_RE = re.compile(r"(です|ます|でした|ました|ません|でしょう|ましょう)[。！？]$")
PLAIN_END_RE = re.compile(r"((?<!まし|でし)た|(?<!で)だ|である)[。！？]$")
PAST_END_RE = re.compile(r"た[。！？]$")
DIALOGUE_RE = re.compile(r"「[^」]*」|『[^』]*』|（[^）]*）")  # 台詞と、（）でくくった心の声


class RulesError(Exception):
    """規則の設定が正しくないときの例外。"""


def merge_rules(base: RulesConfig, override: dict | None) -> RulesConfig:
    """設定ファイルの規則を、文体の [rules] で上書きする。"""
    if not override:
        return base
    try:
        return RulesConfig.model_validate(base.model_dump() | override)
    except ValidationError as e:
        raise RulesError(f"文体の [rules] が正しくありません: {e}") from e


def _compact(text: str) -> str:
    return re.sub(r"\s", "", text)


# ---- 整形 ----


def _pairs(mark: str, length: int) -> str:
    """記号を、2つ組（「……」「――」）にそろえる。"""
    return mark * 2 * max(1, math.ceil(length / 2))


def _normalize_punctuation(text: str, counts: Counter[str]) -> str:
    def ellipsis(m: re.Match) -> str:
        run = m.group(0)
        fixed = _pairs("…", len(run)) if run[0] == "…" else "……"
        if fixed != run:
            counts["三点リーダー"] += 1
        return fixed

    def dash(m: re.Match) -> str:
        run = m.group(0)
        fixed = _pairs("―", len(run))
        if fixed != run:
            counts["ダッシュ"] += 1
        return fixed

    text = re.sub(r"…+|\.{3,}|・{3,}", ellipsis, text)
    text = re.sub(r"[―—─]+", dash, text)
    # 半角の感嘆符・疑問符を全角に
    n = len(re.findall(r"[!?]", text))
    if n:
        text = text.replace("!", "！").replace("?", "？")
        counts["感嘆符・疑問符"] += n
    # 文の途中の「！」「？」のあとに、全角の空白を入れる
    text, n = re.subn(r"([！？]+)(?=[^」』）！？\s])", r"\1　", text)
    counts["感嘆符のあとの空白"] += n
    return text


def normalize(text: str, rules: RulesConfig) -> tuple[str, Counter[str]]:
    """規則に沿って、本文の書き方を整える。整えた本文と、直した箇所の数を返す。

    何度適用しても、結果が変わらない（2回目は何も直さない）ように作る。
    """
    counts: Counter[str] = Counter()
    if rules.punctuation:
        text = _normalize_punctuation(text, counts)
    if not rules.dialogue_period:
        text, n = re.subn(r"。(?=[」』])", "", text)
        counts["台詞の句点"] += n

    paragraphs = []
    for line in text.splitlines():
        line = line.strip()  # 字下げ（全角の空白）も、いったん取り除く
        if not line:
            continue
        if rules.dialogue_new_line:
            # 文の終わりか、台詞の終わりのすぐあとに始まる台詞は、段落を分ける
            parts = re.split(r"(?<=[。！？」』])\s*(?=「)", line)
            counts["台詞の改行"] += len(parts) - 1
            paragraphs += [p for p in parts if p]
        else:
            paragraphs.append(line)
    if rules.indent:
        # 地の文の段落だけを1字下げる。台詞やかっこで始まる段落は下げない
        paragraphs = [p if p[0] in OPEN else "　" + p for p in paragraphs]
    separator = "\n\n" if rules.blank_line else "\n"
    return separator.join(paragraphs), +counts


# ---- 検査 ----

Severity = Literal["error", "warning", "info"]
SEVERITY_NAMES = {"error": "違反", "warning": "警告", "info": "参考"}


@dataclass
class Finding:
    """規則を守れていない箇所1つ。"""

    rule: str  # 規則の名前（RulesConfig のフィールド名）
    label: str  # 短い名前
    severity: Severity  # error: 必ず直す、warning: 多ければ直す、info: 参考（直させない）
    criterion: Criterion  # 批評の観点（第16章）のどれにあたるか
    quote: str  # 本文からの引用。本文全体についての指摘なら空文字列
    problem: str
    suggestion: str

    def to_issue(self) -> Issue:
        """推敲のプロンプト（第16章の scene_revise）に渡す指摘にする。"""
        return Issue(
            criterion=self.criterion,
            label=self.label,
            quote=self.quote,
            problem=self.problem,
            suggestion=self.suggestion,
        )


def split_sentences(paragraph: str) -> list[str]:
    """段落を、文（台詞は台詞ごと）に分ける。かっこの中の句点では分けない。"""
    units: list[str] = []
    start, depth = 0, 0
    for i, ch in enumerate(paragraph):
        after = paragraph[i + 1] if i + 1 < len(paragraph) else ""
        if ch in OPEN:
            depth += 1
        elif ch in CLOSE:
            depth = max(0, depth - 1)
            # 台詞だけの文（「〜」）や、心の声だけの文（（〜））は、閉じかっこで終わる
            if depth == 0 and paragraph[start:].lstrip()[0] in OPEN and after in ("", *OPEN):
                units.append(paragraph[start : i + 1])
                start = i + 1
        elif ch in ENDS and depth == 0 and after not in ENDS:
            units.append(paragraph[start : i + 1])
            start = i + 1
    units.append(paragraph[start:])
    return [u.strip() for u in units if u.strip()]


def is_dialogue(sentence: str) -> bool:
    """台詞（または、（）でくくった心の声）だけの文か。"""
    return sentence[0] in OPEN and sentence[-1] in CLOSE


def _quote(sentence: str) -> str:
    return sentence[:QUOTE_CHARS]


def lint(text: str, rules: RulesConfig) -> list[Finding]:
    """本文の中から、規則を守れていない箇所を探す。"""
    findings: list[Finding] = []
    pronoun_re = re.compile(rf"(?<![一-龥])({'|'.join(FIRST_PERSON)})(?={PARTICLES})")
    narrative: list[str] = []  # 地の文の文（台詞だけの文を除く）
    run: list[str] = []  # 同じ文末が続いている文
    run_ending = ""

    def close_run() -> None:
        if len(run) > rules.max_same_endings:
            findings.append(
                Finding(
                    "max_same_endings",
                    "同じ文末の連続",
                    "warning",
                    "prose",
                    _quote(run[0]),
                    f"「〜{run_ending}」で終わる文が{len(run)}文続いている",
                    "途中の文の文末を、現在形・体言止め・倒置などに変える",
                )
            )

    for paragraph in text.splitlines():
        paragraph = paragraph.strip()
        if not paragraph:
            continue
        if not is_dialogue(paragraph) and len(_compact(paragraph)) > rules.max_paragraph_chars:
            findings.append(
                Finding(
                    "max_paragraph_chars",
                    "長すぎる段落",
                    "warning",
                    "prose",
                    _quote(paragraph),
                    f"段落が{len(_compact(paragraph))}字ある（上限{rules.max_paragraph_chars}字）",
                    "話題や動作の切れ目で、段落を分ける",
                )
            )
        for sentence in split_sentences(paragraph):
            if is_dialogue(sentence):
                close_run()
                run, run_ending = [], ""
                continue
            narrative.append(sentence)
            body = _compact(DIALOGUE_RE.sub("", sentence))  # 文の中の台詞を除いた地の文

            if len(_compact(sentence)) > rules.max_sentence_chars:
                findings.append(
                    Finding(
                        "max_sentence_chars",
                        "長すぎる文",
                        "warning",
                        "prose",
                        _quote(sentence),
                        f"一文が{len(_compact(sentence))}字ある（上限{rules.max_sentence_chars}字）",
                        "2つか3つの文に分ける",
                    )
                )
            if rules.politeness == "plain" and POLITE_END_RE.search(body):
                findings.append(
                    Finding(
                        "politeness",
                        "です・ます調の混入",
                        "error",
                        "prose",
                        _quote(sentence),
                        "地の文が、です・ます調になっている",
                        "だ・である調に直す",
                    )
                )
            if rules.politeness == "polite" and PLAIN_END_RE.search(body):
                findings.append(
                    Finding(
                        "politeness",
                        "だ・である調の混入",
                        "error",
                        "prose",
                        _quote(sentence),
                        "地の文が、だ・である調になっている",
                        "です・ます調に直す",
                    )
                )
            pronouns = {m.group(1) for m in pronoun_re.finditer(body)}
            if rules.person == "third" and pronouns:
                findings.append(
                    Finding(
                        "person",
                        "一人称の混入",
                        "error",
                        "pov",
                        _quote(sentence),
                        f"三人称の地の文に、一人称の「{'」「'.join(sorted(pronouns))}」がある",
                        "視点人物の名前か「彼」「彼女」に直す。心の声なら（）でくくる",
                    )
                )
            other = pronouns - {rules.first_person}
            if rules.person == "first" and other:
                findings.append(
                    Finding(
                        "first_person",
                        "一人称のゆれ",
                        "error",
                        "pov",
                        _quote(sentence),
                        f"語り手の自称が「{'」「'.join(sorted(other))}」になっている",
                        f"語り手の自称は「{rules.first_person}」にそろえる",
                    )
                )

            ending = body[-2:]
            if ending == run_ending:
                run.append(sentence)
            else:
                close_run()
                run, run_ending = [sentence], ending
    close_run()

    # 時制は、本文全体の傾向だけを見る（過去形の文の割合）
    if len(narrative) >= 5:
        past = sum(1 for s in narrative if PAST_END_RE.search(_compact(DIALOGUE_RE.sub("", s))))
        ratio = past / len(narrative)
        if rules.tense == "past" and ratio < 0.3:
            findings.append(
                Finding(
                    "tense",
                    "過去形が少ない",
                    "info",
                    "prose",
                    "",
                    f"地の文のうち、過去形の文が{ratio:.0%}しかない",
                    "過去形を基調にする",
                )
            )
        if rules.tense == "present" and ratio > 0.5:
            findings.append(
                Finding(
                    "tense",
                    "過去形が多い",
                    "info",
                    "prose",
                    "",
                    f"地の文のうち、過去形の文が{ratio:.0%}ある",
                    "現在形を基調にする",
                )
            )
    return findings


def needs_fix(findings: list[Finding], rules: RulesConfig) -> bool:
    """直させるべきか。違反が1件でもあるか、警告が上限を超えていれば直させる。"""
    counts = Counter(f.severity for f in findings)
    return counts["error"] > 0 or counts["warning"] > rules.max_warnings


def fix_issues(findings: list[Finding], limit: int = MAX_ISSUES) -> list[Issue]:
    """直させる指摘。違反を先に、警告をあとに並べ、引用のないものは除く。"""
    order = {"error": 0, "warning": 1}
    fixable = [f for f in findings if f.quote and f.severity in order]
    fixable.sort(key=lambda f: order[f.severity])
    return [f.to_issue() for f in fixable[:limit]]


def summarize(findings: list[Finding]) -> str:
    """検査の結果を1行にまとめる（「違反 2件、警告 3件（長すぎる文 2、…）」）。"""
    if not findings:
        return "問題なし"
    by_severity = Counter(f.severity for f in findings)
    head = "、".join(
        f"{SEVERITY_NAMES[s]} {by_severity[s]}件"
        for s in ("error", "warning", "info")
        if by_severity[s]
    )
    order = list(SEVERITY_NAMES)
    labels = Counter(f.label for f in sorted(findings, key=lambda f: order.index(f.severity)))
    return f"{head}（{'、'.join(f'{label} {n}' for label, n in labels.items())}）"


def describe_rules(rules: RulesConfig) -> str:
    """規則の設定を、1行で説明する。"""
    person = "三人称" if rules.person == "third" else f"一人称（{rules.first_person}）"
    tense = "過去形" if rules.tense == "past" else "現在形"
    politeness = "だ・である調" if rules.politeness == "plain" else "です・ます調"
    layout = [
        "台詞の句点あり" if rules.dialogue_period else "台詞の句点なし",
        "字下げあり" if rules.indent else "字下げなし",
        "空行あり" if rules.blank_line else "空行なし",
    ]
    return "・".join([person, tense, politeness]) + "、" + "、".join(layout)
```

### 整形（normalize）

`normalize` は、次の順に本文を整えます。

1. **記号**（`punctuation`）
   - 「…」「...」「・・・」を「……」にそろえます。「…」が3つなら4つ、というように、2つ組になるように切り上げます。
   - 「―」「—」（英語のダッシュ）「─」（罫線）を、「――」にそろえます。
   - 半角の「!」「?」を全角にし、あとに文が続くときは全角の空白を入れます（「待って！　どこへ」）。閉じかっこや改行の前には入れません。
2. **台詞の句点**（`dialogue_period`）：`False` なら、閉じかっこの直前の「。」を取り除きます。
3. **段落**
   - 各行の前後の空白（字下げの全角空白を含む）と、空の行を、いったん取り除きます。
   - `dialogue_new_line` なら、文の終わり（「。」「！」「？」）か台詞の終わり（「」」）のすぐあとに始まる「「」の前で、段落を分けます。「駅の名は「霧ヶ峰」という。」のように、文の途中にあるかぎかっこでは分けません。「「待って」と葉子が言った。」のように、台詞のあとに地の文が続く段落も、そのままにします。
   - `indent` なら、地の文の段落の頭に全角の空白を入れます。かっこで始まる段落は下げません。これは、台詞の行を字下げしない、日本語の小説の慣習に合わせたものです。
   - `blank_line` なら、段落を空行でつなぎます。

段落の処理で、字下げや空行をいったんすべて取り除いてから付け直すのには、理由があります。`normalize` を**何度適用しても、結果が変わらない**ようにするためです。この性質を**冪等性**（べきとうせい）と言います。執筆のグラフでは、推敲や修正のたびに本文を整えますし、`novelist lint --fix` で、すでに整えた本文をもう一度整えることもあります。冪等でないと、整えるたびに字下げが増える、といったことが起きます。テストでも確かめます（24.8節）。

整形では、全角の空白を字下げに使います。第7章の `text_stats` は空白を数えないので（`\s` は全角の空白にも一致します）、字下げをしても文字数は変わりません。第16章・第21章の引用の確認も、空白を取り除いてから比べているので、影響を受けません。

### 検査（lint）

`lint` は、本文を段落ごとに、段落を文ごとに分けて調べます。

- **文の分け方**（`split_sentences`）：句点・感嘆符・疑問符で分けますが、かっこの中の句点では分けません。「「A。B」と彼は言った。」は1つの文です。台詞だけの文（「「待って」」）は、閉じかっこで区切ります。
- **地の文だけを見る**：台詞だけの文と、（）でくくった心の声は調べません。台詞の中の「私は」や「〜です」は、人物の話し方なので、違反ではありません。台詞と地の文がまざった文（「「行きます」と沢渡は言った。」）は、台詞の部分を取り除いてから調べます。

見つけた箇所は `Finding` にします。重さ（`severity`）は3段階です。

| 重さ | 規則 | 執筆のグラフでの扱い |
|---|---|---|
| 違反（`error`） | 一人称の混入・ゆれ、語尾の混在 | 1件でもあれば直させる |
| 警告（`warning`） | 同じ文末の連続、長すぎる文・段落 | `max_warnings` を超えたら直させる |
| 参考（`info`） | 時制の傾向 | 直させない。ログに出すだけ |

一人称は、「私」「僕」などのあとに助詞（「は」「が」「の」など）が続くものだけを探します。「私鉄」「公僕」のような熟語を、一人称と間違えないためです。直前に漢字がある場合（「公僕は」）も除きます。

時制は、1つの文ごとには判断できません。過去形の小説にも、現在形の文（「雪が降っている。」）や体言止めは混ざりますし、混ざるほうが文章にリズムが出ます。そこで、本文全体で過去形の文の割合を見て、極端に少ない（3割未満）ときだけ「参考」として知らせます。

## 24.4 検査の結果を指摘にする

`Finding` の `to_issue` で、第16章の批評の指摘（`Issue`）に変えます。`Issue` の形にしておけば、第16章の推敲のプロンプト（`scene_revise`）で、そのまま直させられます。第21章でも、食い違いを `FixRequest` にして、同じプロンプトで直させました。

`fix_issues` は、違反を先に、警告をあとに並べ、引用のないもの（本文全体についての指摘）を除いて、最大8件（`MAX_ISSUES`）の指摘にします。1回の推敲で多くの箇所を直させると、LLMが直しきれなかったり、ほかの部分まで書き換えてしまったりするからです。

`needs_fix` は、直させるべきかを決めます。違反は1件でもあれば直させます。警告は、`max_warnings`（既定は3）を超えたときだけ直させます。長すぎる文が1つあるだけで、シーン全体をLLMに書き直させるのは、割に合わないからです。

"""書いたシーンが、文章の規則を守れているかを検査し、直させるノード（第24章）。"""

from typing import Literal

from langgraph.runtime import Runtime

from novelist.graph.nodes.write import (
    MIN_RATIO,
    WRITE_TOKENS_RATIO,
    current_scene,
    scene_brief,
    stream_scene,
    with_style,
    writing_rules,

from novelist.graph.state import WriteContext, WriteState
from novelist.rules import SEVERITY_NAMES, fix_issues, lint, needs_fix, summarize


def check_rules(state: WriteState, runtime: Runtime[WriteContext]) -> dict:
    """本文の中から、規則を守れていない箇所を探す。多ければ、直させる指摘を作る。"""
    rules = writing_rules(runtime.context)
    findings = lint(state["text"], rules)
    log = [f"文章の規則: {summarize(findings)}"]
    log += [f"  [{SEVERITY_NAMES[f.severity]}] {f.label}: {f.quote or f.problem}" for f in findings]
    issues = fix_issues(findings) if needs_fix(findings, rules) else []
    return {"rule_issues": issues, "log": log}


def route_after_rules(
    state: WriteState, runtime: Runtime[WriteContext]
) -> Literal["fix_rules", "summarize_scene"]:
    """直させる違反があり、まだ直せるなら直す。そうでなければ要約へ進む。"""
    max_fixes = writing_rules(runtime.context).max_fixes
    if state["rule_issues"] and state["rule_fixes"] < max_fixes:
        return "fix_rules"
    return "summarize_scene"


def fix_rules(state: WriteState, runtime: Runtime[WriteContext]) -> dict:
    """規則の違反を直すように、シーンを推敲する。"""
    ctx = runtime.context
    brief = scene_brief(state, runtime)
    messages = ctx.prompts.render(
        "scene_revise",
        meta=state["meta"],
        world=state["world"],
        brief=brief,
        text=state["text"],
        rules=writing_rules(ctx),
        issues=state["rule_issues"],
    )
    messages = with_style(messages, state, runtime)
    draft = stream_scene(ctx, messages, int(brief.scene.chars * WRITE_TOKENS_RATIO))
    fixes = state["rule_fixes"] + 1
    if draft.chars < current_scene(state).chars * MIN_RATIO:
        # 直す過程で短くなりすぎた。直す前の原稿のままにする
        return {
            "rule_fixes": fixes,
            "log": [f"規則の修正{fixes}回目: 短くなりすぎたので採用しません"],
        }
    return {
        "text": draft.text,
        "chars": draft.chars,
        "rule_fixes": fixes,
        "log": [f"規則の修正{fixes}回目: {draft.describe()}"],
    }

- 作品に文体を設定していれば（第23章）、文体の `[rules]` も使います。`--style` で別の文体を指定することもできます。

## 24.9 うまくいかないときは

**心の声が、一人称の違反になる**

「（どうして、私はここに来たのだろう）」のように、視点人物の心の声を地の文に書くと、一人称の混入として見つかります。心の声は、かっこでくくれば地の文ではなくなり、違反になりません。指摘の直し方にも「心の声なら（）でくくる」と書いてあるので、LLMがそのように直すこともあります。

地の文の中に心の声を溶け込ませる書き方（自由間接話法）を使いたい場合は、一人称の検査は向いていません。`rules.py` の `lint` で、`person` の検査の重さを `"warning"` に変えるなど、自分の作品に合わせて調整してください。

**直させても、違反が残る**

`max_fixes` を2に増やしてみてください。それでも残る場合は、プロンプトの規則と、文体の見本（第23章）が食い違っていないかを確かめてください。たとえば、見本が一人称で書かれているのに `person = "third"` にしていると、LLMは見本のほうに引っぱられます。

**直させたら、ほかの部分まで書き換わった**

第16章の推敲のプロンプトは、「指摘された箇所を直す。指摘されていない部分は、できるだけそのまま残す」と指示していますが、モデルによっては全体を書き直してしまいます。`max_warnings` を大きくして、警告では直させないようにすると、書き直しの回数が減ります。違反だけを直させたい場合は、`fix_issues` で警告を除くように変えてください。

**台詞でないところで、段落が分かれる**

「〜と言った。「霧ヶ峰」という駅名は〜」のように、文の頭でかぎかっこを使うと、台詞の改行の対象になります。書名や駅名などの引用には、二重かぎかっこ（『』）を使うか、`dialogue_new_line = false` にしてください。

**以前に書いたシーンの書き方がそろっていない**

整形は、本文を書くときにしか行われません。この章より前に書いたシーンや、手で直したシーンは、`novelist lint 作品のID --fix` で整えてください。`indent` や `blank_line` を変えたときも、同じように整え直せます。原稿（`manuscript.md`）は、そのあとで `novelist write` を実行すると書き出し直されます。

## 24.10 まとめ

- 日本語の小説の書き方の規則を、**プロンプトで指示するもの**（人称・時制・語尾・文と段落の長さ）、**後処理で整えるもの**（記号・台詞の句点と改行・字下げ・空行）、**検査してLLMに直させるもの**（一人称の混入・語尾の混在・同じ文末の連続・長すぎる文）に分けて扱いました
- 整形は、本文を生成するたびに `stream_scene` の最後で行います。何度適用しても結果が変わらない（冪等な）処理にしました
- 検査は、プログラムが本文から箇所を切り出して指摘を作り、第16章の推敲のプロンプトでLLMに直させます。違反は1件でも、警告は多いときだけ直させます
- 規則は `novelist.toml` の `[rules]` で選べ、文体（第23章）の `[rules]` で上書きできます
- `novelist lint` で、書いたシーンを検査し、`--fix` で整えられるようになりました

これで、文体を見本で伝え（第23章）、規則で縛る（第24章）仕組みがそろいました。しかし、同じプロンプトと規則でも、使うモデルや量子化、サンプリングの設定によって、書かれる文章は大きく変わります。第25章では、同じプロットで複数のモデルや設定に書かせ、この章の `lint` や第7章の統計、第16章の批評を使って比べる**評価ハーネス**を作ります。
