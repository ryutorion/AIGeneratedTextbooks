# 第30章 長編の構造 — 部・章・シーンの階層、章単位要約の積み上げ

第VII部では、ここまで短編（1万字前後）で作ってきた仕組みを、**長編**（10万字前後）に広げます。第12章の `novelist new` には、最初から `--length long`（目標10万字）がありましたが、実際に長編を書こうとすると、いくつもの問題にぶつかります。

- **プロットを一度に作れない**：10万字なら、シーンは50前後になります。50枚のシーンカードを1回のJSONで出力させると、出力が長くなりすぎ、途中で切れたり、前半と後半で辻つまが合わなくなったりします。第14章のプロットは、章を8つまでにしていました
- **先の計画は外れる**：書き進めるうちに、本文は少しずつプロットから離れていきます。物語の後半のシーンカードを、書き始める前に細かく決めておいても、そのとおりには書けません
- **あらすじが長くなりすぎる**：第15章から、シーンを書くたびに「これまでのあらすじ」としてシーンの要約を渡してきました。50シーン分の要約は、それだけで1万字近くになります。第20章の予算では、古いあらすじから省くので、物語の前半で置いた伏線や約束が、後半を書くときには消えてしまいます

この章では、長編を**部・章・シーン**の3段の階層で扱い、これらの問題を解決します。

| ファイル・コマンド | 内容 |
|---|---|
| `src/novelist/schemas/outline.py` | 部と章からなるアウトラインと、章・部の要約のモデル |
| `src/novelist/longform.py` | アウトラインを作る・章のシーンカードを作る・要約を積み上げる |
| `src/novelist/graph/nodes/longform.py` | 執筆のグラフで、章を広げ、章と部を要約するノード |
| `prompts/outline/`・`chapter_scenes/`・`chapter_summary/`・`part_summary/` | それぞれのプロンプト |
| `novelist outline` | アウトラインと、書き進み具合を表示する |
| `novelist summarize` | 書き終えた章と部の要約を作る |

## 30.1 部・章・シーン

### 3段の階層

長編を、次の3段に分けます。

| 階層 | 10万字の長編での目安 | 決めること | いつ決めるか |
|---|---|---|---|
| 部 | 3〜4部 | 物語の大きな区切り（起・承・転・結など）と、部の終わりの状況 | 書き始める前（アウトライン） |
| 章 | 全体で15〜20章、1章6,000字前後 | 章で起きることと、章の終わりの状況、章の重さ | 書き始める前（アウトライン） |
| シーン | 1章に2〜4シーン | シーンカード（第14章） | **その章を書く直前** |

書き始める前に決めるのは、**部と章**までです。これを**アウトライン**と呼びます。アウトラインは、物語全体の流れと、伏線をどの章で置いてどの章で回収するかを決めるためのもので、シーンの細部は決めません。

シーンカードは、その章を書く直前に作ります。そのときには、前の章までの本文がすでに書かれています。実際に書かれた内容（の要約）を見ながら、次の章のシーンを決めるので、計画と本文のずれが積み重なりません。

```text
novelist plan（書き始める前）
  アウトライン: 第1部 ─ 第1章・第2章・第3章・…
               第2部 ─ 第6章・第7章・…
               …
  第1章のシーンカード

novelist write（書きながら）
  第1章のシーンを書く ─▶ 第1章を要約する ─▶ 第2章のシーンカードを作る ─▶ 第2章のシーンを書く ─▶ …
                                               ↑ 第1章の要約を見て作る
```

このように、近い先だけを細かく決め、遠い先は大まかに決めておく計画の立て方は、ソフトウェア開発などでもよく使われます。

### 文字数の配分

第14章では、シーンの重さ（シーンカードの目安の文字数の比）で、作品の目標の文字数を配分しました。長編でも、同じ考え方を2段で使います。

1. アウトラインの章ごとの**重さ**（1〜5）の比で、作品の目標の文字数を章に配分する
2. 章のシーンカードの目安の文字数の比で、章の文字数をシーンに配分する

どちらも、LLMには比だけを決めさせ、合計を合わせるのはプログラムで行います。第14章の `distribute` を、そのまま使います。

## 30.2 要約を積み上げる

### 要約のピラミッド

あらすじが長くなりすぎる問題は、要約を**積み上げる**ことで解決します。

```text
              部の要約（600字）           ← 部を書き終えたら、章の要約から作る
             ／          ＼
   章の要約（400字）  章の要約 …        ← 章を書き終えたら、シーンの要約から作る
   ／    ｜    ＼
シーンの要約（200字）…                   ← シーンを書き終えたら、本文から作る（第15章）
```

シーンの要約は、第15章から作ってきたものです。章を書き終えたら、その章のシーンの要約を読ませて、**章の要約**を作ります。部を書き終えたら、その部の章の要約を読ませて、**部の要約**を作ります。章や部の要約を作るときには本文を読まないので、LLMに渡す量は少なく済みます。

### 3段のあらすじ

シーンを書くときの「これまでのあらすじ」は、古いものほど大きな単位でまとめます。たとえば、第3部の第12章の2つめのシーンを書くときは、次のようになります。

```text
第1部「雪の夜」: （部の要約）
第2部「疑惑」: （部の要約）
第11章「…」: （章の要約）           ← 第3部の、前の章
12-1「…」: （シーンの要約）          ← 今の章の、前のシーン
```

| | 平らなあらすじ（第15章） | 3段のあらすじ |
|---|---|---|
| 中身 | 55シーンの要約 | 部の要約2つ・章の要約1つ・シーンの要約1つ |
| 長さの目安 | 約8,000字 | 約2,000字 |

あらすじの長さは、物語が進んでも、ほとんど増えません。第20章の予算で古いあらすじを省くことも、まずなくなります。

要約の要約を作るたびに、細かいことは落ちていきます。そこで、章と部の要約のプロンプトには、「あとで回収される謎、置かれた手がかり、人物どうしの約束や対立は、省かずに書く」と指示します。それでも落ちた細部は、第19章の検索（過去の本文を探す）と、第22章のストーリーステート（人物の居場所・持ち物・知っていること）が補います。

```python
"""長編の骨組み（アウトライン）と、章・部の要約（第30章）。"""

import math

from pydantic import BaseModel, Field, ValidationInfo, model_validator

from novelist.schemas.plot import Scene, bible_hint, distribute, scene_errors

CHAPTER_MIN_CHARS = 3000  # 1章の目安の文字数の下限
CHAPTER_MAX_CHARS = 20000  # 1章の目安の文字数の上限
CHAPTER_STANDARD_CHARS = 6000  # 章の数の目安を決めるときの、1章の標準の文字数
CHAPTER_SCENE_CHARS = 2500  # 章のシーンの数の目安を決めるときの、1シーンの標準の文字数


def chapter_count_range(target_chars: int) -> tuple[int, int]:
    """目標の文字数に収められる、章の数の範囲。"""
    low = math.ceil(target_chars / CHAPTER_MAX_CHARS)
    high = math.floor(target_chars / CHAPTER_MIN_CHARS)
    return max(low, 2), high


def standard_chapter_count(target_chars: int) -> int:
    """プロンプトで指示する、章の数の目安。"""
    low, high = chapter_count_range(target_chars)
    return min(max(round(target_chars / CHAPTER_STANDARD_CHARS), low), high)


class OutlineChapter(BaseModel):
    """アウトラインの章。シーンカードは、この章を書く直前に作る。"""

    title: str = Field(description="章の見出し", max_length=30)
    summary: str = Field(
        description="この章で起きること。章の終わりに、状況がどう変わるかまで書く", max_length=200
    )
    weight: int = Field(
        description="章の重さ（1〜5）。山場の章は大きく、つなぎの章は小さくする", ge=1, le=5
    )


class Part(BaseModel):
    """部。物語の大きな区切り（起・承・転・結など）。"""

    title: str = Field(description="部の見出し", max_length=30)
    summary: str = Field(
        description="この部で起きること。部の終わりに、物語がどこまで進むかまで書く",
        max_length=300,
    )
    chapters: list[OutlineChapter] = Field(min_length=2, max_length=8)


class Outline(BaseModel):
    """長編の骨組み。部と章だけを決め、シーンは決めない。"""

    parts: list[Part] = Field(min_length=2, max_length=5)

    def chapters(self) -> list[tuple[int, int, OutlineChapter]]:
        """すべての章を、(部の番号, 章の番号, 章) の組で返す。章の番号は通し番号（1から）。"""
        result, n = [], 0
        for p, part in enumerate(self.parts, start=1):
            for chapter in part.chapters:
                n += 1
                result.append((p, n, chapter))
        return result

    def chapter(self, number: int) -> OutlineChapter:
        """通し番号の章。"""
        return self.chapters()[number - 1][2]

    def part_of(self, chapter: int) -> int:
        """章が、何部にあるか。"""
        return self.chapters()[chapter - 1][0]

    def chapters_of(self, part: int) -> list[int]:
        """部にある章の、通し番号のリスト。"""
        return [n for p, n, _ in self.chapters() if p == part]

    def chapter_targets(self, target_chars: int) -> list[int]:
        """章ごとの目安の文字数。作品の目標の文字数を、章の重さの比で配分する。"""
        weights = [chapter.weight for _, _, chapter in self.chapters()]
        return distribute(target_chars, weights, CHAPTER_MIN_CHARS, CHAPTER_MAX_CHARS)

    @model_validator(mode="after")
    def _check_count(self, info: ValidationInfo) -> "Outline":
        """章の数が、目標の文字数に合っているかを確かめる（context に target_chars があるとき）。"""
        target = (info.context or {}).get("target_chars")
        if target is None:
            return self
        low, high = chapter_count_range(target)
        count = len(self.chapters())
        if not low <= count <= high:
            raise ValueError(
                f"章の数（{count}個）を、全体で{low}〜{high}個にしてください"
                f"（1章{CHAPTER_MIN_CHARS}〜{CHAPTER_MAX_CHARS}字で、合計を約{target}字にするため）"
            )
        return self


class ChapterScenes(BaseModel):
    """1つの章のシーンカード。LLMに作らせ、プログラムで Chapter にする。"""

    scenes: list[Scene] = Field(min_length=2, max_length=8)

    @model_validator(mode="after")
    def _check_against_bible(self, info: ValidationInfo) -> "ChapterScenes":
        """人物と場所が設定資料にあるかを確かめる（第14章の Plot と同じ検証）。"""
        context = info.context or {}
        names, places = context.get("character_names"), context.get("place_names")
        labeled = [(f"シーン{j}「{s.title}」", s) for j, s in enumerate(self.scenes, start=1)]
        errors = scene_errors(labeled, names, places)
        if errors:
            raise ValueError("\n".join(errors) + bible_hint(names, places))
        return self
```

## 30.4 長編の工程

**`src/novelist/longform.py`**（新規）

```python
"""長編を、部・章・シーンの階層で扱う（第30章）。

- アウトライン（部と章）を先に作り、章のシーンカードは、その章を書く直前に作る
- 章を書き終えたら章の要約を、部を書き終えたら部の要約を作り、あらすじを積み上げる
"""

import math
from dataclasses import dataclass

from novelist.config import Config
from novelist.llm.client import LLMClient
from novelist.llm.structured import generate_structured, schema_text
from novelist.prompts import PromptLibrary
from novelist.schemas.bible import CharacterSheet, WorldSheet
from novelist.schemas.outline import (
    CHAPTER_SCENE_CHARS,
    ChapterScenes,
    ChapterSummary,
    Digest,
    Outline,
    PartSummary,
    chapter_count_range,
    standard_chapter_count,
)
from novelist.schemas.plot import (
    SCENE_MAX_CHARS,
    SCENE_MIN_CHARS,
    Chapter,
    Plot,
    distribute,
    plot_context,
)
from novelist.schemas.scene import SceneRecord, scene_key
from novelist.schemas.work import WorkMeta
from novelist.work import Work

PROFILE = "precise"  # 構成と要約は、正確さを優先する
PLAN_MAX_TOKENS = 8192  # アウトラインとシーンカードは長くなるので、多めに確保する


# ---- アウトライン ----


def make_outline(
    client: LLMClient,
    prompts: PromptLibrary,
    config: Config,
    meta: WorkMeta,
    world: WorldSheet,
    characters: CharacterSheet,
    feedback: str | None = None,
    previous: Outline | None = None,
) -> Outline:
    """企画と設定資料から、部と章からなるアウトラインを作る。"""
    low, high = chapter_count_range(meta.target_chars)
    messages = prompts.render(
        "outline",
        meta=meta,
        world=world,
        characters=characters,
        chapter_count=standard_chapter_count(meta.target_chars),
        chapter_low=low,
        chapter_high=high,
        schema=schema_text(Outline),
        feedback=feedback,
        previous=previous,
    )
    return generate_structured(
        client,
        messages,
        Outline,
        _sampling(config),
        validation_context={"target_chars": meta.target_chars},
    )


def _sampling(config: Config):
    sampling = config.sampling_for(PROFILE)
    return sampling.model_copy(update={"max_tokens": max(sampling.max_tokens, PLAN_MAX_TOKENS)})


# ---- 章のシーンカード ----


def chapter_scene_range(target_chars: int) -> tuple[int, int]:
    """章の目安の文字数に収められる、シーンの数の範囲（2〜8個）。"""
    low = max(2, math.ceil(target_chars / SCENE_MAX_CHARS))
    high = max(low, min(8, math.floor(target_chars / SCENE_MIN_CHARS)))
    return low, high


def expand_chapter(
    client: LLMClient,
    prompts: PromptLibrary,
    config: Config,
    meta: WorkMeta,
    world: WorldSheet,
    characters: CharacterSheet,
    outline: Outline,
    number: int,
    story_so_far: list[str],
    feedback: str | None = None,
    previous: Chapter | None = None,
) -> Chapter:
    """アウトラインの第 number 章を、シーンカードに分ける。

    章の目安の文字数はアウトラインの重さから、シーンの目安の文字数はシーンカードの比から、
    プログラムで決める（第14章の fit_to と同じ考え方）。
    """
    target = outline.chapter_targets(meta.target_chars)[number - 1]
    low, high = chapter_scene_range(target)
    count = min(max(round(target / CHAPTER_SCENE_CHARS), low), high)
    planned = outline.chapter(number)
    messages = prompts.render(
        "chapter_scenes",
        meta=meta,
        world=world,
        characters=characters,
        outline=outline,
        number=number,
        story_so_far=story_so_far,
        scene_count=count,
        scene_low=low,
        scene_high=high,
        scene_min=SCENE_MIN_CHARS,
        scene_max=SCENE_MAX_CHARS,
        target_chars=target,
        schema=schema_text(ChapterScenes),
        feedback=feedback,
        previous=previous,
    )
    context = plot_context(world, characters, None)
    result = generate_structured(
        client, messages, ChapterScenes, _sampling(config), validation_context=context
    )
    chars = distribute(target, [s.chars for s in result.scenes], SCENE_MIN_CHARS, SCENE_MAX_CHARS)
    scenes = [s.model_copy(update={"chars": c}) for s, c in zip(result.scenes, chars, strict=True)]
    return Chapter(title=planned.title, summary=planned.summary, scenes=scenes)


def add_chapter(plot: Plot | None, chapter: Chapter) -> Plot:
    """プロットの最後に章を足した、新しいプロットを返す。"""
    if plot is None:
        return Plot(chapters=[chapter])
    return plot.model_copy(update={"chapters": [*plot.chapters, chapter]})


# ---- あらすじの積み上げ ----


@dataclass
class SummaryBook:
    """アウトラインと、書き終えた章・部の要約。"""

    outline: Outline
    chapters: dict[int, Digest]  # 章の番号 → 章の要約
    parts: dict[int, Digest]  # 部の番号 → 部の要約

    @classmethod
    def load(cls, work: Work) -> "SummaryBook | None":
        """作品の要約を読み込む。アウトラインのない作品（短編）なら None。"""
        outline = work.load_outline()
        if outline is None:
            return None
        chapters = {}
        for _, n, _ in outline.chapters():
            if (digest := work.load_digest("chapter", n)) is not None:
                chapters[n] = digest
        parts = {}
        for p in range(1, len(outline.parts) + 1):
            if (digest := work.load_digest("part", p)) is not None:
                parts[p] = digest
        return cls(outline, chapters, parts)


def layered_summaries(
    plot: Plot,
    records: dict[str, SceneRecord],
    chapter_no: int,
    scene_no: int,
    book: SummaryBook,
) -> list[str]:
    """第 chapter_no 章のシーン scene_no を書くための「これまでのあらすじ」を、3段で作る。

    - 前の部のうち、部の要約があるもの → 部の要約を1行
    - それ以外の前の章のうち、章の要約があるもの → 章の要約を1行
    - それ以外（今の章の前のシーンと、要約のない章のシーン）→ シーンの要約を1行ずつ
    """
    lines: list[str] = []
    covered: set[int] = set()  # 部や章の要約で、まとめて書いた章
    current_part = book.outline.part_of(chapter_no)
    for p in range(1, current_part):
        if (digest := book.parts.get(p)) is not None:
            lines.append(f"第{p}部「{digest.title}」: {digest.summary}")
            covered.update(book.outline.chapters_of(p))
    for i, j, scene in plot.scenes():
        if (i, j) >= (chapter_no, scene_no):
            break
        if i in covered:
            continue
        if i < chapter_no and (digest := book.chapters.get(i)) is not None:
            lines.append(f"第{i}章「{digest.title}」: {digest.summary}")
            covered.add(i)
            continue
        key = scene_key(i, j)
        if key in records:
            lines.append(f"{key}「{scene.title}」: {records[key].summary}")
    return lines


def chapter_done(plot: Plot, records: dict[str, SceneRecord], number: int) -> bool:
    """章のシーンを、すべて書き終えたか。"""
    if number > len(plot.chapters):
        return False
    return all(
        scene_key(number, j) in records for j in range(1, len(plot.chapters[number - 1].scenes) + 1)
    )


def part_done(outline: Outline, plot: Plot, records: dict[str, SceneRecord], part: int) -> bool:
    """部の章を、すべて書き終えたか。"""
    return all(chapter_done(plot, records, n) for n in outline.chapters_of(part))


def summarize_chapter(
    client: LLMClient,
    prompts: PromptLibrary,
    config: Config,
    plot: Plot,
    records: dict[str, SceneRecord],
    number: int,
) -> Digest:
    """書き終えた章を、シーンの要約から要約する。本文は読まない。"""
    chapter = plot.chapters[number - 1]
    lines = [
        f"{scene_key(number, j)}「{scene.title}」: {records[scene_key(number, j)].summary}"
        for j, scene in enumerate(chapter.scenes, start=1)
    ]
    messages = prompts.render(
        "chapter_summary",
        number=number,
        chapter=chapter,
        scene_summaries=lines,
        schema=schema_text(ChapterSummary),
    )
    result = generate_structured(client, messages, ChapterSummary, config.sampling_for(PROFILE))
    return Digest(number=number, title=chapter.title, summary=result.summary)


def summarize_part(
    client: LLMClient,
    prompts: PromptLibrary,
    config: Config,
    outline: Outline,
    chapters: dict[int, Digest],
    number: int,
) -> Digest:
    """書き終えた部を、章の要約から要約する。"""
    part = outline.parts[number - 1]
    digests = [chapters[n] for n in outline.chapters_of(number)]
    messages = prompts.render(
        "part_summary", number=number, part=part, chapters=digests, schema=schema_text(PartSummary)
    )
    result = generate_structured(client, messages, PartSummary, config.sampling_for(PROFILE))
    return Digest(number=number, title=part.title, summary=result.summary)
```

### 章のシーンカードを作る

`expand_chapter` は、アウトラインの1つの章を、シーンカードに分けます。

1. `chapter_targets` で、その章の目安の文字数を決めます。
2. `chapter_scene_range` で、その文字数に収められるシーンの数の範囲を決めます。1シーン500〜4,000字（第14章）に収めるためです。

4. シーンカードの目安の文字数を、章の目安の文字数に合わせて配分し直します。
5. 見出しと内容をアウトラインから取って、`Chapter` にします。

```python
    plot = add_chapter(plot, chapter)
    ctx.work.save_plot(plot)
    keys = [scene_key(number, j) for j in range(1, len(chapter.scenes) + 1)]
    limit = state.get("limit")
    if limit is not None:
        keys = keys[: limit - state.get("written", 0)]
    total = sum(scene.chars for scene in chapter.scenes)
    part = outline.part_of(number)
    return {
        "plot": plot,
        "queue": keys,
        "total": state["total"] + len(keys),
        "log": [
            f"第{part}部 第{number}章「{chapter.title}」のシーンカードを作りました"
            f"（{len(chapter.scenes)}シーン、合計 {total:,}字） → {ctx.work.plot_path}"
        ],
    }


def _current_chapter(state: WriteState) -> int:
    """今書き終えたシーンの、章の番号。"""
    return parse_scene_key(state["current"])[0]


def _last_in_chapter(state: WriteState) -> bool:
    """今書き終えたシーンが、章の最後のシーンか。"""
    i, j = parse_scene_key(state["current"])
    return j == len(state["plot"].chapters[i - 1].scenes)


def route_after_scene_saved(
    state: WriteState,
) -> Literal["summarize_chapter", "start_scene", "expand_chapter", "export"]:
    """長編で、章の最後のシーンを書き終えたら、章を要約する。そうでなければ次へ。"""
    if state.get("outline") is not None and _last_in_chapter(state):
        return "summarize_chapter"
    return route_next(state)


def summarize_chapter_node(state: WriteState, runtime: Runtime[WriteContext]) -> dict:
    """書き終えた章を、シーンの要約から要約して保存する。"""
    ctx = runtime.context
    number, _ = parse_scene_key(state["current"])
    digest = summarize_chapter(
        ctx.client, ctx.prompts, ctx.config, state["plot"], state["records"], number
    )
    ctx.work.save_digest("chapter", digest)
    return {"log": [f"第{number}章の要約: {digest.summary}"]}


def route_after_chapter(
    state: WriteState,
) -> Literal["summarize_part", "start_scene", "expand_chapter", "export"]:
    """部の最後の章を書き終えたら、部を要約する。そうでなければ次へ。"""
    number = _current_chapter(state)
    outline = state["outline"]
    if outline.chapters_of(outline.part_of(number))[-1] == number:
        return "summarize_part"
    return route_next(state)


def summarize_part_node(state: WriteState, runtime: Runtime[WriteContext]) -> dict:
    """書き終えた部を、章の要約から要約して保存する。"""
    ctx = runtime.context
    outline = state["outline"]
    part = outline.part_of(_current_chapter(state))
    book = SummaryBook.load(ctx.work)
    missing = [n for n in outline.chapters_of(part) if n not in book.chapters]
    if missing:
        return {
            "log": [
                f"第{part}部の要約は作りません"
                f"（章の要約がない章: {', '.join(map(str, missing))}）。"
                f"novelist summarize {ctx.work.slug} で作れます"
            ]
        }
    digest = summarize_part(ctx.client, ctx.prompts, ctx.config, outline, book.chapters, part)
    ctx.work.save_digest("part", digest)
    return {"log": [f"第{part}部の要約: {digest.summary}"]}
```

## 30.11 うまくいかないときは

**アウトラインが作れない（章の数のエラーが続く）**

LLMが、指示した章の数を守れていません。部の数と章の数を数え間違えることが多いので、小さいモデルで起きやすい問題です。`novelist.toml` の `precise` プロファイルで思考を止めている場合は、思考を許すと数を守りやすくなることがあります。それでも作れない場合は、第17章と同じく、`outline.json` を手で書いてから `novelist plan` を実行すると、アウトラインを作らずに第1章のシーンカードから始めます。

**章のシーンカードが、アウトラインの章の内容から外れる**

前の章の本文が、アウトラインの予定から離れていると、LLMは本文の流れとアウトラインの間で迷います。`outline.json` の、まだ書いていない章の内容を、実際の流れに合わせて直してください。シーンカードを作る前なら、直した内容が使われます。

**章の要約に、大事な手がかりが入っていない**

`summaries/chapter-NN.json` を手で直してください。次の章からは、直した要約が使われます。シーンの要約（`scenes/NN-NN.json` の `summary`）に手がかりが書かれていない場合は、そちらも直してから、`novelist summarize 作品のID --force` で作り直します。

**部の要約が作られない**

部の要約は、部のすべての章に章の要約があるときだけ作ります。`novelist outline 作品のID` で「✓要約」がない章を探し、`novelist summarize 作品のID` を実行してください。

**長編を書き終えるまでに、時間がかかりすぎる**

10万字の長編では、シーンの執筆・推敲・一貫性チェック・状態の更新などで、LLMを数百回呼び出します。手元のGPUでは、まる1日以上かかることもあります。夜のうちに書かせる方法や、途中で止まっても続きから書く方法は、第32章で扱います。

## 30.12 まとめ

- 長編を**部・章・シーン**の3段に分けました。書き始める前には部と章（**アウトライン**）だけを決め、章のシーンカードは、その章を書く直前に、書き終えた章の要約を見ながら作ります
- 文字数は、章の重さで作品の目標を章に配分し、シーンカードの比で章をシーンに配分する、2段の配分にしました
- 章を書き終えたらシーンの要約から**章の要約**を、部を書き終えたら章の要約から**部の要約**を作り、**要約を積み上げ**ました
- シーンを書くときのあらすじを、前の部は部の要約、前の章は章の要約、今の章はシーンの要約という**3段**にしました。物語が進んでも、あらすじの長さはほとんど増えません
- `novelist outline` で書き進み具合を確かめ、`novelist summarize` で要約を作り直せるようにしました

アウトラインには「どの章で伏線を置き、どの章で回収するか」を書かせましたが、それが本当に置かれ、回収されたかは、まだ確かめていません。第31章では、**伏線トラッカー**で伏線を登録し、回収されたかを確かめます。また、1つの長編を超えて、巻をまたぐ**シリーズ**の設定を引き継ぐ方法も扱います。
