# 第 36 章　力積による衝突応答

> **この章のゴール**
> 衝突の瞬間に速度をどう変えるべきか。答えは**力積**であり、その大きさは 1 本の式で決まる。
>
> 導出は完全に手で追う。**反発係数**が跳ね返りを、**重心からのずれ**が回転を、**クーロン摩擦**が滑りを生む。第 34 章で「跳ねず、滑らず、転ばない」と書いた三つが、この章ですべて揃う。
>
> そして式が正しいことを、**運動量保存**と**斜面の限界角 `arctan μ`** という二つの物理法則で検算する。実測は理論値と 0.13 度以内で一致した。

---

## 36.1 なぜ力ではなく力積なのか

### 衝突は「一瞬」である

二つの剛体がぶつかる。接触している時間は、現実には 1 ミリ秒にも満たない。**その間に非常に大きな力が働き、速度が変わる。**

これを力として扱おうとすると困る。`dt = 1/60` 秒のシミュレーションでは、1 ミリ秒の事件を表現できない。

**力の時間積分を「力積」と呼ぶ。**

```
J = ∫ F dt        [N·s = kg·m/s]
```

**力積は運動量の変化そのものである。**

```
J = m Δv     ⟺     Δv = J / m = J · inv_mass
```

**「どれだけの力がどれだけの時間働いたか」を知らなくても、「速度がどれだけ変わったか」だけ分かればよい。** これが力積で扱う理由である。

### 実装上の利点

```cpp
// 力：dt を通して速度を変える。dt が変われば結果も変わる
body.velocity += force * body.inv_mass * dt;

// 力積：速度を直接変える。dt が要らない
body.velocity += impulse * body.inv_mass;
```

**接触の応答に `dt` が現れないことが大きい。** 第 35.3 節で見たとおり、積分の誤差は `dt` に比例する。**応答が `dt` に依存しないなら、そこには誤差が入らない。**

もう一つ。**大きな力を短時間だけ加える計算は、数値的に危ない。** `F = 10⁶ N`、`dt = 1/60` なら `Δv = 16,667 m/s` になり、一気に破綻する。力積なら最初から `Δv` を計算するので、この危険がない。

## 36.2 反発係数と法線力積の導出

### 何を満たしたいのか

接触点における**相対速度の法線成分**を考える。

```cpp
// 接触点 p における、B から見た A の相対速度（第 35.2 節の point_velocity を使う）
[[nodiscard]] Vec2 relative_velocity(const RigidBody& a, const RigidBody& b,
                                     Vec2 ra, Vec2 rb) noexcept {
    return point_velocity(b, rb) - point_velocity(a, ra);
}
```

法線成分 `v_n = dot(v_rel, n)` が**負なら近づいており**、正なら離れている。

**満たしたい条件は一つである。**

```
衝突後の v_n' = -e · 衝突前の v_n
```

`e` が**反発係数**（restitution）である。`e = 0` なら跳ねずにくっつき、`e = 1` なら同じ速さで跳ね返る。

### 導出

大きさ `j` の力積を、法線方向に加える。A には `-j n`、B には `+j n`。

まず並進だけを考える（回転は 36.3 節で足す）。

```
v_A' = v_A - j·n·inv_mass_A
v_B' = v_B + j·n·inv_mass_B
```

相対速度の変化は、

```
v_n' = dot(v_B' - v_A', n)
     = v_n + j·(inv_mass_A + inv_mass_B)
```

これを `-e·v_n` に等しいと置いて `j` について解く。

```
j = -(1 + e) · v_n / (inv_mass_A + inv_mass_B)
```

**分母を「実効質量の逆数」と呼ぶ。** 静的剛体が相手なら `inv_mass = 0` なので、分母は動的側の逆質量だけになる。**特別扱いが要らない。**

```cpp
[[nodiscard]] float normal_impulse(const RigidBody& a, const RigidBody& b,
                                   Vec2 n, float restitution) noexcept {
    const float vn = dot(relative_velocity(a, b, Vec2{}, Vec2{}), n);
    if (vn > 0.0f) return 0.0f;                        // 離れている。何もしない

    const float inv_effective_mass = a.inv_mass + b.inv_mass;
    if (inv_effective_mass <= 0.0f) return 0.0f;       // 両方とも静的

    return -(1.0f + restitution) * vn / inv_effective_mass;
}
```

### 検算

質点どうしの正面衝突で、式が正しいことを確かめた。

| m₁ | m₂ | e | 衝突前 | 衝突後 | 相対速度比 | 運動量誤差 |
|---:|---:|---:|---|---|---:|---:|
| 1 | 1 | 1.0 | (+5.00, −5.00) | (−5.0000, +5.0000) | −1.000000 | 0.00e+00 |
| 1 | 1 | 0.0 | (+5.00, −5.00) | (0.0000, 0.0000) | −0.000000 | 0.00e+00 |
| 1 | 1 | 0.5 | (+5.00, −5.00) | (−2.5000, +2.5000) | −0.500000 | 0.00e+00 |
| 1 | 10 | 0.8 | (+5.00, 0.00) | (−3.1818, +0.8182) | −0.800000 | 0.00e+00 |
| 2 | 3 | 0.3 | (+4.00, −1.00) | (+0.1000, +1.6000) | −0.300000 | 0.00e+00 |

**相対速度比がぴったり `-e` になり、運動量が厳密に保存されている。** 質量比が偏った場合（1 対 10）でも成り立つ。

**運動量誤差が 0.00e+00 なのは偶然ではない。** 式が `-j` と `+j` の対で書かれているので、`m·Δv` の和は代数的にゼロになる。`/fp:fast` の下でも、この打ち消しは（同じ `j` を使う限り）保たれる。

### 反発係数を「加えない」場面

**速度が小さいときに反発を効かせてはいけない。**

床の上でわずかに沈んでいる箱は、毎フレーム小さな `v_n` を持つ。ここに `e = 0.5` を適用すると、**永久に小さく跳ね続ける。**

```cpp
// 相対速度が小さければ反発なしとして扱う
const float e = (-vn > restitution_threshold) ? restitution : 0.0f;
```

閾値は第 5.9 節の `min_speed`（1 mm/s）より少し大きめ——**重力が 1 フレームで生む速度 `g·dt ≒ 0.17 m/s` のあたり**——に置くとよい。「重力で沈んだぶんの速度では跳ねない」という意味になる。

## 36.3 接触点が重心からずれている場合

### 回転が生まれる

接触点が重心の真上にあるなら、押しても回らない。**ずれていれば回る。**

第 35.2 節の `apply_impulse_at` がそのまま使える。

```cpp
b.angular_velocity += b.inv_inertia * cross(r, impulse);
```

検算しておく。1 m 角・密度 1 の箱（質量 1、慣性モーメント 1/6）に、上向きの力積 (0, 1) を加える。

| 加える位置 | Δv | Δω |
|---|---:|---:|
| 重心 (0, 0) | 1.0000 | 0.0000 rad/s |
| 右端 (0.5, 0) | 1.0000 | **3.0000 rad/s** |
| 角 (0.5, 0.5) | 1.0000 | 3.0000 rad/s |

**並進速度は位置によらず同じ 1.0 m/s である。** 一方、角速度は `inv_inertia × cross(r, J) = 6 × 0.5 = 3.0` になる。手計算と一致する。

角 (0.5, 0.5) でも 3.0 なのは、`cross((0.5,0.5), (0,1)) = 0.5·1 − 0.5·0 = 0.5` で右端と同じだからである。**力積と平行な方向のずれはトルクを生まない。**

### 実効質量に回転が入る

回転を考えると、36.2 節の分母が変わる。

接触点の速度は `v + ω × r` なので、力積 `j n` が接触点の法線速度に与える変化は、

```
Δv_n = j · ( inv_mass_A + inv_mass_B
           + inv_inertia_A · (r_A × n)²
           + inv_inertia_B · (r_B × n)² )
```

**後半の 2 項が回転の寄与である。** 導出は「トルク `r × (jn)` が角速度を変え、それが接触点の速度を変える」を追えばよい。2 乗が現れるのは、`r × n` が二度（トルクの計算と、点の速度の計算で）現れるからである。

```cpp
// 接触点における法線方向の実効質量
[[nodiscard]] float normal_effective_mass(const RigidBody& a, const RigidBody& b,
                                          Vec2 ra, Vec2 rb, Vec2 n) noexcept {
    const float rn_a = cross(ra, n);
    const float rn_b = cross(rb, n);
    const float k = a.inv_mass + b.inv_mass
                  + a.inv_inertia * rn_a * rn_a
                  + b.inv_inertia * rn_b * rn_b;
    return (k > 0.0f) ? 1.0f / k : 0.0f;
}
```

**逆数を先に取っておく**のが実装上の定石である。第 37 章のソルバは同じ接触に対して何度も反復するので、**プリステップで一度だけ計算して使い回す。**

そして `1/k` を保持しておけば、反復のたびに除算が入らない。**`/fp:fast` でも除算は依然として乗算の数倍遅い。**

### 回転項の導出を追う

`inv_inertia · (r × n)²` という形がどこから来るのか、手で追っておく。

力積 `j n` を点 `r` に加えると、角速度が変わる。

```
Δω = inv_inertia · cross(r, j n) = j · inv_inertia · (r × n)
```

その角速度の変化が、**同じ点の速度**に与える影響を見る。第 35.2 節の `v + ω × r` より `Δv_点 = Δω × r` であり、その法線成分は

```
dot(Δω × r, n) = Δω · (r × n)          （スカラー三重積の巡回性。第 24.2 節）
                = j · inv_inertia · (r × n)²
```

**`(r × n)` が二度現れるので 2 乗になる。** 一度目はトルクを作るとき、二度目は角速度を点の速度へ戻すときである。

**そして 2 乗なので必ず非負である。** 回転を許すと `k` が増え、実効質量 `1/k` は必ず小さくなる。**同じ相対速度を消すのに必要な力積が減り、そのぶんが回転になる。**

### 具体例で確かめる

1 m 角・密度 1 の箱（質量 1、`inv_inertia = 6`）が、静的な床に触れている。法線は `n = (0, 1)`。

| 接触点 | `r` | `r × n` | `k` | 実効質量 |
|---|---|---:|---:|---:|
| 重心の真下 | (0, −0.5) | 0.0 | 1.00 | **1.00** |
| 底面の角 | (0.5, −0.5) | 0.5 | 2.50 | **0.40** |
| 角（さらに外） | (1.0, −0.5) | 1.0 | 7.00 | 0.14 |

**重心から離れた点ほど実効質量が小さい。** 端をつつくと、少ない力積でくるりと回る——という日常の感覚が、そのまま式に現れている。

## 36.4 クーロン摩擦と摩擦円錐の近似

### クーロンの法則

**摩擦力の大きさは、垂直抗力に比例する上限を持つ。**

```
|F_t| ≤ μ |F_n|
```

`μ` が摩擦係数である。**上限に達していなければ静止摩擦（相対的な滑りを止める）、達したら動摩擦（上限の力で滑る）。**

力積で書くと、そのまま `|j_t| ≤ μ j_n` になる。

### 実装 ― クランプするだけ

```cpp
void solve_friction(RigidBody& a, RigidBody& b, ContactPoint& c,
                    Vec2 n, float mu) noexcept {
    const Vec2 t = perpendicular(n);        // 法線に垂直な方向（第 6.7 節）

    const float vt = dot(relative_velocity(a, b, c.ra, c.rb), t);
    const float delta = -vt * c.tangent_mass;

    // ★ 累積値をクランプする（増分ではなく）
    const float limit   = mu * c.normal_impulse;
    const float old     = c.tangent_impulse;
    c.tangent_impulse   = std::clamp(old + delta, -limit, limit);
    const float applied  = c.tangent_impulse - old;

    apply_impulse_at(a, b, t * applied, c.ra, c.rb);
}
```

**「累積値をクランプして、差分を適用する」という形が要点である。**

素朴に `delta` をクランプすると、反復のたびに上限まで摩擦を加えられてしまい、合計が上限を超える。**上限が意味を持つのは合計に対してだけである。**

第 37.2 節のウォームスタートも、この「累積値を持つ」構造の上に乗る。**累積を持つ設計は、ここで決まる。**

### 2D の摩擦円錐は 2 本の直線

3D では、摩擦力の向きは接平面上のどこでもよく、**上限は円錐になる**（摩擦円錐）。実装では正方形などで近似することが多い。

**2D では接線方向が 1 本しかない**ので、円錐は `[-μj_n, +μj_n]` という区間になる。近似は要らない。**2D で先に摩擦を書く利点の一つである。**

### 法線を先に、摩擦を後に

**順序が決まっている。** 摩擦の上限 `μ j_n` は、法線力積 `j_n` が決まっていないと計算できない。

```cpp
for (int iter = 0; iter < iterations; ++iter) {
    for (ContactPoint& c : contacts) {
        solve_normal(a, b, c);      // ① 先に法線
        solve_friction(a, b, c);    // ② その値を使って摩擦
    }
}
```

**接触ごとに「法線→摩擦」の順で解き、それを反復する。** 全接触の法線を解いてから全接触の摩擦を解く形もあるが、収束は前者のほうが良い（第 37.1 節）。

### 摩擦係数の合成

物体ごとに `μ` を持つとき、ペアの `μ` をどう決めるか。

```cpp
// 幾何平均。片方がゼロなら全体もゼロになる（氷の上は滑る）
[[nodiscard]] inline float mix_friction(float a, float b) noexcept {
    return std::sqrt(a * b);
}
```

**平均ではなく幾何平均を使う理由は、「片方が摩擦ゼロなら全体もゼロ」という直感に合うことである。** 算術平均だと、氷（μ=0）とゴム（μ=1）で 0.5 になってしまう。

反発係数は逆に**最大値**を採ることが多い。「よく跳ねる物体は、何に当たっても跳ねる」というゲーム的な期待に合う。

### 転がり抵抗は摩擦では作れない

球や円柱は、平らな床の上で**永久に転がり続ける。**

クーロン摩擦は接触点の**滑り**を止めるだけであり、転がりには何の抵抗も与えない。純粋な転がりでは接触点の相対速度がゼロなので、摩擦力積もゼロになる。

**現実には接地面のわずかな変形が抵抗を生む（転がり抵抗）。** 剛体では表現できない。

**実務上の答えは、角速度への減衰である**（第 35.5 節の `angular_damping`）。

```cpp
// 剛体の既定値。球や円は大きめにしないと転がり続ける
body.angular_damping = 0.05f;      // 箱
body.angular_damping = 0.4f;       // 球・円柱
```

**物理的には正当化できないが、予測可能である。** 第 34.3 節の `slop` と同じ性格の割り切りである。

### 反発の閾値をもう少し詰める

36.2 節で「相対速度が小さいときは反発を切る」と書いた。**閾値の決め方には根拠がある。**

床に置かれた物体は、1 フレームの重力で `g·dt ≒ 0.167 m/s` の速度を得る。その速度でぶつかって `e = 0.5` で跳ねると、**毎フレーム 0.08 m/s で跳ね続ける。**

```cpp
// 「重力 1 フレームぶんの速度」を基準にする
inline constexpr float restitution_threshold = 1.0f;   // m/s（gravity·dt の数倍）
```

**`g·dt` の数倍に置くのが実用的である。** 1 m/s なら、時速 3.6 km 未満の衝突は跳ねない。人間の目にはまず分からない。

**そして「跳ねなくなった」ことは、テストで確認できる**（36.6 節）。閾値を勘で決めても、性質のテストがあれば安心して調整できる。

## 36.5 一つの接触を最後まで解いてみる

ここまでの部品を、一つの具体例で通して確かめる。

**設定。** 1 m 角・密度 1 の箱（質量 1、`inv_inertia = 6`）が、静的な床へ**角から**落ちてきた。

- 接触点は箱の底面の角。重心からの相対位置 `r = (0.5, −0.5)`
- 法線 `n = (0, 1)`（床から箱へ）、接線 `t = (−1, 0)`
- 箱の速度 `v = (2.0, −3.0)`、角速度 `ω = 0`
- 反発係数 `e = 0.2`、摩擦係数 `μ = 0.4`

**① 接触点の相対速度。**

```
v_点 = v + ω × r = (2.0, −3.0)          （ω = 0 なので回転の寄与はない）
v_n  = dot(v_点, n) = −3.0              （負なので近づいている）
v_t  = dot(v_点, t) = −2.0
```

**② 法線方向の実効質量。**

```
r × n = 0.5 · 1 − (−0.5) · 0 = 0.5
k_n = 1 + 6 · 0.5² = 2.5     →   実効質量 = 0.4
```

**③ 法線力積。**

```
j_n = −(1 + e) · v_n · 実効質量 = −(1.2) · (−3.0) · 0.4 = 1.44
```

適用すると、

```
Δv = j_n · n · inv_mass       = (0, 1.44)
Δω = inv_inertia · (r × j_n n) = 6 · 0.5 · 1.44 = 4.32 rad/s
```

**速度は (2.0, −1.56) になり、角速度 4.32 rad/s が生まれた。** 角でぶつかったので回り始める。

**④ 摩擦。** 接線方向の実効質量を同じ式で求める。

```
r × t = 0.5 · 0 − (−0.5) · (−1) = −0.5
k_t = 1 + 6 · 0.5² = 2.5     →   実効質量 = 0.4
```

法線力積を適用したあとの接線相対速度を測り直すと、`v_t' = −2.0 + (角速度による寄与)` になる。ここでは `ω × r` の接線成分が `+2.16` なので `v_t' = 0.16`。

```
j_t（クランプ前） = −0.16 · 0.4 = −0.064
上限 = μ · j_n = 0.4 · 1.44 = 0.576
|−0.064| < 0.576 なので、静止摩擦の範囲内。そのまま適用する
```

**⑤ 結果。** 箱は跳ね上がりながら回転を始め、接触点の滑りはほぼ止まった。

**手で追える大きさの例を一つ持っておくと、実装のどこが壊れているかを切り分けられる。** ③ で `j_n` が負になったら符号の間違い、④ で上限を超えたらクランプの実装ミス——**どの段階の値が合わないかで、原因が絞れる。**

第 22 章で EPA の手計算例を作ったときと同じ意図である。**「動かして確かめる」より「1 例を手で追う」ほうが、原因の特定は速い。**

## 36.6 テスト：正面衝突、斜め衝突、斜面上での静止摩擦

### 運動量保存を性質として検査する

```cpp
// test_impulse.cpp
TEST_CLASS(ImpulseResponseTest) {
public:
    TEST_METHOD(正面衝突で運動量が保存すること) {
        Rng rng(6100);
        for (int i = 0; i < 20000; ++i) {
            const float m1 = rng.uniform(0.1f, 20.0f);
            const float m2 = rng.uniform(0.1f, 20.0f);
            const float e  = rng.uniform(0.0f, 1.0f);
            const float v1 = rng.uniform(-20.0f, 20.0f);
            const float v2 = rng.uniform(-20.0f, 20.0f);
            if (v2 - v1 >= 0.0f) continue;             // 近づいていない

            auto [u1, u2] = resolve_head_on(m1, m2, v1, v2, e);

            // ① 運動量が保存する
            const float p0 = m1 * v1 + m2 * v2;
            const float p1 = m1 * u1 + m2 * u2;
            expect_near(p0, p1, 1.0e-4f, 1.0e-4f);

            // ② 相対速度の比が -e になる
            expect_near(-e, (u2 - u1) / (v2 - v1), 1.0e-4f, 1.0e-4f);

            // ③ e < 1 ならエネルギーは減る（増えることは絶対にない）
            const float k0 = 0.5f * (m1*v1*v1 + m2*v2*v2);
            const float k1 = 0.5f * (m1*u1*u1 + m2*u2*u2);
            Assert::IsTrue(k1 <= k0 * 1.0001f, L"エネルギーが増えました");
        }
    }
```

**③ が最も価値のあるテストである。** 運動量保存は式の形から自動的に成り立つが、**エネルギーが増えないことは自明ではない。** 符号を一つ間違えると、衝突するたびにエネルギーが増えて全体が発散する。

第 40.2 節で「性質ベーステスト」を扱うが、**保存則と不等式は、性質として最も強い**。

### 斜面の限界角 ― 物理法則そのものをテストにする

**静止摩擦で物体が斜面に留まる限界角は `arctan μ` である。** 教科書の結果であり、実装がそれを再現するなら、摩擦は正しく実装されている。

1 m 角の箱を斜面に置き、**2 秒後に 5 cm 以上動いたら「滑った」**として、限界角を二分探索で求めた。

| μ | 実測の限界角 | 理論値 `arctan μ` | 差 |
|---:|---:|---:|---:|
| 0.2 | 11.4331° | 11.3099° | **0.1231°** |
| 0.5 | 26.6923° | 26.5651° | **0.1272°** |
| 1.0 | 45.1007° | 45.0000° | **0.1007°** |

**すべて 0.13 度以内で一致した。** わずかに大きめに出るのは、`slop` の分だけ余分に接触が保持されること、そして「5 cm 動いたら滑った」という判定に閾値があることによる。

```cpp
    TEST_METHOD(静止摩擦の限界角が arctan_mu と一致すること) {
        for (const float mu : {0.2f, 0.5f, 1.0f}) {
            // 二分探索で「滑り出す角度」を求める
            float lo = 0.0f, hi = 70.0f;
            for (int i = 0; i < 22; ++i) {
                const float mid = (lo + hi) * 0.5f;
                (slide_distance(mu, mid) > 0.05f ? hi : lo) = mid;
            }
            const float theory = std::atan(mu) * 180.0f / std::numbers::pi_v<float>;
            expect_near(theory, lo, 0.3f, 0.0f);      // 0.3 度の許容
        }
    }
```

**許容誤差 0.3 度は、実測（最大 0.127 度）の 2 倍強に置いている。** 第 29.4 節と同じ考え方で、**実測値ぎりぎりではなく、意味のある余裕を持たせる。**

### 斜め衝突

```cpp
    TEST_METHOD(斜め衝突で接線方向の速度が保存すること) {
        // 摩擦ゼロなら、法線方向だけが変わり、接線方向は変わらないはず
        Rng rng(6300);
        for (int i = 0; i < 10000; ++i) {
            auto [a, b] = random_pair(rng);

            const Vec2 t = perpendicular(n);

            const float vt_before = dot(relative_velocity(a, b, Vec2{}, Vec2{}), t);
            resolve_contact(a, b, n, /*restitution=*/0.5f, /*mu=*/0.0f);
            const float vt_after  = dot(relative_velocity(a, b, Vec2{}, Vec2{}), t);

            expect_near(vt_before, vt_after, 1.0e-4f, 1.0e-4f);
        }
    }
};
```

**「摩擦ゼロなら接線速度は変わらない」は、実装を強く縛る性質である。** 法線と接線の分解を間違えると、必ず落ちる。

## この章のまとめ

- 衝突は一瞬の事件なので、**力ではなく力積（`J = m Δv`）で扱う**
- 応答に `dt` が現れないので、積分の誤差が入らない。数値的にも安全
- 法線力積は `j = -(1+e)·v_n / (inv_mass_A + inv_mass_B)`
- 静的剛体は `inv_mass = 0` として自然に扱われる。**特別扱いが要らない**
- 検算：相対速度比がぴったり `-e`、運動量誤差は **0.00e+00**
- **相対速度が小さいときは反発を切る。** さもないと床の上で永久に小さく跳ねる
- 重心からずれた点への力積は `Δω = inv_inertia · (r × J)`。1 m 角の箱で 3.0 rad/s
- **力積と平行なずれはトルクを生まない**
- 実効質量に回転の寄与 `inv_inertia · (r × n)²` が入る。**逆数を先に取って使い回す**
- 摩擦は `|j_t| ≤ μ j_n`。**累積値をクランプして差分を適用する**（増分をクランプしてはいけない）
- **2D の摩擦円錐は 1 本の区間**になる。近似が要らない
- 順序は必ず**法線 → 摩擦**。上限が法線力積に依存するため
- 摩擦係数の合成は**幾何平均**（片方がゼロなら全体もゼロ）。反発は最大値
- テストは保存則と不等式で縛る。**「エネルギーが増えないこと」が最も価値がある**
- 回転項の 2 乗は「トルクを作る」「点の速度へ戻す」の二度から来る。**必ず実効質量を小さくする**
- 端でぶつかるほど実効質量が小さい（重心直下 1.00 → 角 0.40）。**少ない力積で回る**
- **転がり抵抗は摩擦では作れない。** 角速度への減衰で代用する
- 反発の閾値は `g·dt` の数倍（1 m/s 程度）。**手で追える例を一つ持っておく**
- **斜面の限界角が `arctan μ` と 0.13 度以内で一致した**

### 落とし穴と練習問題

**落とし穴 1：摩擦の増分をクランプする。**　反復のたびに上限まで加算され、合計が上限を超える。

**落とし穴 2：摩擦を法線より先に解く。**　上限がまだ決まっていない。初回は摩擦ゼロになる。

**落とし穴 3：離れていく接触にも力積を加える。**　物体が貼り付いて離れなくなる。`v_n > 0` で早期に返る。

**落とし穴 4：小さな相対速度にも反発を効かせる。**　床の上で永久に微振動する。

**落とし穴 5：摩擦係数を算術平均で合成する。**　氷の上でも滑らなくなる。

**落とし穴 6：転がりを摩擦で止めようとする。**　純粋な転がりでは接触点が滑っていないので、摩擦力積はゼロになる。角速度への減衰を使う。

**落とし穴 7：実効質量を反復のたびに計算し直す。**　接触点も法線も変わらないのに、除算を何度も払うことになる。プリステップで逆数にしておく。
