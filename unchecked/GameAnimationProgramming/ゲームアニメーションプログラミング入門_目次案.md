# ゲームアニメーションプログラミング入門 ― 目次案

## 本書の方針

| 項目 | 決定内容 |
| --- | --- |
| 環境 | Visual Studio 2026 / C++23（**C++ モジュールは使用しない**） |
| 外部ライブラリ | 原則不使用。JSON パーサ・数学ライブラリ・テストデータ生成もすべて自作 |
| モデルデータ | glTF 2.0 を自前パーサで読み込む（`.gltf` + `.bin`、および `.glb`） |
| 検証方法 | 描画は行わず、**単体テスト**で全章を検証（Visual Studio 付属 Microsoft Native Unit Test） |
| 形式 | ハンズオン。1 章 = 1 つの小さな成果物 + それを守るテスト |
| 読者 | C++ の基本文法を理解している人。線形代数は本書内で必要分を再構築する |
| 到達点 | LBS / DQS スキニング、glTF 再生、ブレンドツリーとステートマシン、IK（2ボーン・CCD・FABRIK）、キーフレーム圧縮と GPU スキニング |

**章の共通フォーマット**

1. この章で作るもの（1〜2 文）
2. 動機 ― 前章のコードの何が足りないか
3. 実装（小刻みなコード追加。1 ステップ 10〜40 行程度）
4. 単体テスト（先にテストを書く章と、後から書く章を意識的に混ぜる）
5. まとめと次章への橋渡し

全 10 部 / 全 63 章 / 付録 5 本。

## 第 I 部　準備 ― テストで守られた土台をつくる

### 第 1 章　本書の地図

- ゲームのアニメーションが「毎フレーム何を計算しているのか」を 1 枚の図で俯瞰する
- スケルトン → ポーズ → スキニング行列パレット → 頂点変形、という一本道を最初に示す
- 本書で作る成果物と、章ごとの依存関係マップ
- 「描画しないのにどうやって正しさを確認するのか」への回答

### 第 2 章　ソリューションを作る

- 静的ライブラリ `AnimLib` + テストプロジェクト `AnimLib.Tests` の 2 プロジェクト構成
- C++23 の有効化（`/std:c++latest`）、警告レベル `/W4 /WX`、モジュールを使わないヘッダ構成の指針
- Microsoft Native Unit Test の追加とテストエクスプローラーでの実行
- **単体テスト**: `Assert::AreEqual(2, 1 + 1)` が通るところまで

### 第 3 章　最初のテストヘルパー

- 浮動小数点を `AreEqual` で比較してはいけない理由
- 許容誤差付きアサート `AssertNear` / `AssertNearVec` を自作する
- 失敗メッセージを読める形にする（`ToString<T>` の特殊化）
- **単体テスト**: 意図的に失敗するテストを書いてメッセージを確認する

### 第 4 章　浮動小数点とアニメーション

- ゲームのアニメーションで蓄積する誤差はどこで生まれるか（補間・行列の連鎖・正規化）
- `/fp:fast` を採用する理由と、そのときテストで守るべき誤差の桁
- 局所的に `/fp:precise` に戻す場面（`#pragma float_control`）
- 非正規化数と FTZ/DAZ ― ブレンドウェイトが 0 に漸近するときの速度低下
- **単体テスト**: 誤差の累積を 10,000 フレーム回して許容範囲に収まることを確認

## 第 II 部　数学 ― 姿勢を表す道具を自作する

### 第 5 章　ベクトル

- `Vec3` / `Vec4` の実装（演算子、内積、外積、長さ、正規化）
- ゼロ長ベクトルの正規化をどう扱うか（例外か、ゼロを返すか、契約か）
- **単体テスト**: 外積の右手系、三角不等式、正規化後の長さ

### 第 6 章　行列

- `Mat4` の実装と、**行優先 / 列優先・行ベクトル / 列ベクトルの決定**（本書は行ベクトル × 行優先で統一）
- 平行移動・回転・スケール行列、合成順序
- **単体テスト**: 単位行列、合成の結合則、既知の点の変換結果

### 第 7 章　行列の逆行列

- 一般の逆行列と、剛体変換に限定した高速な逆変換
- **単体テスト**: `M * inverse(M) == I`、剛体版と一般版の一致

### 第 8 章　クォータニオン

- なぜオイラー角ではだめなのか（ジンバルロック、補間の破綻）
- `Quat` の実装（積、共役、逆、正規化）
- **単体テスト**: 単位元、積の非可換性、共役との積が単位元

### 第 9 章　クォータニオンと回転

- 軸角 ⇔ クォータニオン、クォータニオン ⇔ 行列の相互変換
- 行列 → クォータニオンの数値的に安定な実装（Shepperd の分岐）
- **単体テスト**: 往復変換の一致、退化ケース（180 度回転）

### 第 10 章　クォータニオンの補間

- Lerp / Nlerp / Slerp の違いを角速度の一定性で理解する
- **最短経路問題**（内積が負なら片方を反転する）
- Slerp の特異点（ほぼ同一の回転）を Nlerp にフォールバック
- **単体テスト**: t=0/1 の端点一致、中点の角度、逆向き回転での最短経路

### 第 11 章　Transform

- スケール・回転・平行移動をまとめた `Transform`（SRT）構造体
- 合成・逆変換・点の変換・方向の変換
- 行列表現との相互変換、非一様スケールの落とし穴
- **単体テスト**: `Transform` の合成と `Mat4` の合成が一致すること

### 第 12 章　デュアルクォータニオン

- 二重数と `DualQuat` の実装（第 22 章の DQS への布石）
- 剛体変換の表現、正規化、点の変換
- **単体テスト**: `Transform` と同じ変換結果になること、合成の一致

## 第 III 部　スケルトン ― 骨組みを組み立てる

### 第 14 章　ポーズ

- ローカルポーズ（各ボーンの親からの相対 `Transform`）の表現
- グローバルポーズの計算 ― 親から順に 1 パスで解く
- 再帰版から反復版へ書き換える
- **単体テスト**: 2 ボーンの腕モデルで手先のワールド位置を手計算と照合

### 第 15 章　バインドポーズと逆バインド行列

- レストポーズ / バインドポーズ / 現在のポーズの三者の違いを図で整理

- **単体テスト**: バインドポーズのままなら変換が恒等になること

### 第 16 章　スキニング行列パレット

- `skinMatrix[i] = globalPose[i] * inverseBind[i]` の導出
- パレットを毎フレーム再構築するバッファ設計

## 第 IV 部　スキニング ― メッシュを変形させる

### 第 17 章　スキンメッシュのデータ構造

### 第 18 章　リニアブレンドスキニング（LBS）

- 本書のクライマックスその 1。CPU で頂点を変形する
- **単体テスト**: 1 ボーン 100% なら剛体変換と一致、2 ボーン 50:50 の中間位置

### 第 19 章　法線と接線のスキニング

- 法線に平行移動を掛けてはいけない、非一様スケールでは逆転置行列が要る
- 実務上の近似（回転のみ適用）とその妥当な範囲
- **単体テスト**: スケール付きボーンで法線が面に直交し続けること

### 第 20 章　スキニングを速くする

- 頂点ごとのループを AoS から SoA へ、影響ボーン数での分岐排除
- ボーン 1 本 / 2 本 / 4 本の専用パスを持つ
- **単体テスト**: 最適化前後で結果が誤差内で一致（ゴールデンテスト）

### 第 21 章　LBS の限界

- キャンディラッパー現象・肘のへこみを、テストで**数値として**検出する
- 「見た目の破綻」を体積やねじれ角で定量化する手法
- **単体テスト**: 180 度ねじった関節で体積が潰れることを確認（失敗を確認するテスト）

### 第 22 章　デュアルクォータニオンスキニング（DQS）

- DQS の実装（ブレンド、符号合わせ、正規化）
- 第 21 章のテストを DQS で通す
- DQS の弱点（膨らみ、スケール非対応）と使い分け
- **単体テスト**: 第 21 章と同じねじれで体積が保たれること

## 第 VIII 部　IK ― ポーズを後から曲げる

### 第 46 章　IK とは何か

- FK と IK。ゲームで IK が必要になる場面（足の接地、武器の保持、注視）
- IK チェーンの表現と、IK 適用後にポーズが壊れないための制約

### 第 47 章　2 ボーン IK

- 解析解。余弦定理で肘角を決め、極ベクトル（Pole Vector）で肘の向きを決める
- 目標が届かない / 近すぎる場合の処理
- **単体テスト**: 手先が目標に一致すること、届かない場合に最大伸長になること

### 第 48 章　CCD IK

- 末端から根元へ 1 関節ずつ回す反復解法
- 反復回数と収束判定
- **単体テスト**: 収束後の誤差が閾値以下、反復回数の上限内で収束

### 第 49 章　FABRIK

- 位置ベースの前進 / 後退パス。CCD との挙動の違い
- **単体テスト**: ボーン長が保存されること、収束

### 第 50 章　関節制限とルックアット

- ヒンジ制限・円錐制限、CCD / FABRIK への組み込み
- 頭と目のルックアット（制限付き、複数ボーンへの分配）
- **単体テスト**: 制限角を超えないこと、目標方向との角度誤差

### 第 51 章　フット IK

- 地面の高さに合わせた足の接地補正（レイキャストの結果は与えられるものとする）
- 足首の姿勢を地面法線に合わせる、腰の下げ幅、時間方向のスムージング
- **単体テスト**: 与えた地形高さに対する足先の位置、段差でのスムージング挙動

### 第 58 章　GPU スキニング

- CPU スキニングを GPU へ移す ― パレットを構造化バッファで送る設計
- HLSL の頂点シェーダ（LBS / DQS 両方）
- **描画せずに検証する**: Compute Shader で変形結果を読み戻し、CPU 実装と突き合わせる
- **単体テスト**: GPU 変形結果と CPU 変形結果が誤差内で一致

### 第 59 章　更新の間引きと LOD

- 距離による更新頻度の低下、ボーン LOD、画面外カリング
- 間引き時の補間（前回ポーズとの補間で「カクつき」を隠す）
- **単体テスト**: 間引きありでも位置誤差が閾値以下

## 検討メモ

- **章数を減らしたい場合**の統合候補：第 30〜31 章（JSON パーサ）を 1 章に、第 54〜56 章（圧縮）を 2 章に、第 6〜7 章（行列）を 1 章に。最短で全 60 章程度。
