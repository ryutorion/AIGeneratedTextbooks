# 第 41 章　部分ブレンド（ボーンマスク）

**この章で作るもの**：ブレンドの効果を体の一部に限定する `BoneMask`。「走りながら手を振る」を、走りクリップと手振りクリップの 2 本で実現します。

---

## 41.1　上半身だけ別の動き

前章の加算ブレンドは、**クリップの組み合わせ爆発**を解決しました。しかし、まだ足りない場面があります。

**手を振りながら走る。** 手振りは「差分」ではなく、腕の姿勢を**完全に置き換える**動きです。加算では表現できません。

必要なのは、**ブレンドをボーンごとに制御すること**です。

```
ボーン          走り     手振り    結果
root            100%      0%      走り
spine           100%      0%      走り
chest             0%    100%      手振り
  rightArm        0%    100%      手振り
    rightHand     0%    100%      手振り
leftLeg         100%      0%      走り
```

**ボーンごとに重みを持つ配列**、それがボーンマスクです。

---

## 41.2　`BoneMask`

```cpp
// AnimLib/include/anim/BoneMask.h
#pragma once

#include "anim/PoseBlend.h"
#include "anim/Skeleton.h"

namespace anim {

// ボーンごとのブレンド重み。0 = 基底のまま、1 = オーバーレイで置き換え。
class BoneMask {
public:
    void Resize(std::size_t boneCount) { weights_.assign(boneCount, 0.0f); }
    void Fill(float value) { std::fill(weights_.begin(), weights_.end(), value); }

    void Set(BoneIndex bone, float weight) { weights_[bone] = weight; }
    [[nodiscard]] float Weight(BoneIndex bone) const { return weights_[bone]; }
    [[nodiscard]] std::size_t Size() const noexcept { return weights_.size(); }

    // root 以下の部分木すべてに value を設定する。
    void SetSubtree(const Skeleton& skeleton, BoneIndex root, float value);

    // 親から子へ向かって滑らかに変化させる（41.4 節）。
    void Smooth(const Skeleton& skeleton, int steps);

private:
    std::vector<float> weights_;
};

// mask に従って base と overlay を混ぜる。
inline void BlendPoseMasked(const Pose& base, const Pose& overlay,
                            const BoneMask& mask, Pose& out,
                            RotationBlend mode = RotationBlend::Nlerp) {
    ANIM_ASSERT(mask.Size() == base.Size());
    for (std::size_t i = 0; i < base.Size(); ++i) {
        const BoneIndex bone = static_cast<BoneIndex>(i);
        const float w = mask.Weight(bone);

        if (w <= 0.0f) {
            out[bone] = base[bone];              // ← ビット単位でそのまま
        } else if (w >= 1.0f) {
            out[bone] = overlay[bone];           // ← ビット単位でそのまま
        } else {
            out[bone] = BlendTransform(base[bone], overlay[bone], w, mode);
        }
    }
}

}  // namespace anim
```

**重み 0 と 1 を特別扱いしている**のが重要です。

`BlendTransform(a, b, 0.0f, ...)` は数学的には `a` を返しますが、`Nlerp` を通るので**正規化による丸めが入ります**。長さが 1 からわずかにずれた回転が、正規化されて元と違う値になる。差は `1e-7` 程度ですが、**「マスク外のボーンは一切変化しない」という保証が失われます**。

分岐を入れることで、**マスク外のボーンはビット単位で不変**になります。これは性能のためではなく、**性質の保証**のためです。テストで `==` による厳密な比較ができるようになります。

## 41.3　部分木への設定

「胸から先すべて」を指定したい。第 13 章の不変条件が、ここで効きます。

```cpp
void BoneMask::SetSubtree(const Skeleton& skeleton, BoneIndex root, float value) {
    weights_[root] = value;

    // 親は必ず自分より前にいる（第 13 章）ので、前から 1 パスで済む
    for (std::size_t i = static_cast<std::size_t>(root) + 1;
         i < skeleton.BoneCount(); ++i) {
        const BoneIndex bone = static_cast<BoneIndex>(i);
        const BoneIndex parent = skeleton.ParentOf(bone);
        if (parent != kNoParent && IsInSubtree(skeleton, parent, root)) {
            weights_[bone] = value;
        }
    }
}

// bone が root の部分木に含まれるか。親をたどるだけ。
[[nodiscard]] inline bool IsInSubtree(const Skeleton& skeleton,
                                      BoneIndex bone, BoneIndex root) {
    for (BoneIndex b = bone; b != kNoParent; b = skeleton.ParentOf(b)) {
        if (b == root) { return true; }
    }
    return false;
}
```

**`root + 1` から始められる**のが、トポロジカル順序の恩恵です。`root` より前のボーンが `root` の子孫であることは、原理的にありえません。

さらに効率的な書き方もあります。**親のマスク値を伝播させる**方式です。

```cpp
// 親のマスク値を子に伝える。1 パスで済む。
void BoneMask::PropagateFromRoots(const Skeleton& skeleton) {
    for (std::size_t i = 0; i < skeleton.BoneCount(); ++i) {
        const BoneIndex bone = static_cast<BoneIndex>(i);
        const BoneIndex parent = skeleton.ParentOf(bone);
        if (parent != kNoParent && weights_[bone] < 0.0f) {   // -1 = 未設定
            weights_[bone] = weights_[parent];
        }
    }
}
```

「未設定」を負の値で表し、親から継承させます。**ボーン 1 本ぶんの設定で、部分木全体が決まる**ので、マスクの定義が簡潔になります。

## 41.4　境界の不連続と、その緩和

素朴なマスク（0 か 1 か）には問題があります。**境界で姿勢が急に切り替わる**のです。

```
spine  : 走りの姿勢
chest  : 手振りの姿勢    ← ここで不連続
```

脊椎と胸のあいだで、腰から上の向きが突然変わる。**人体としてありえない曲がり方**になります。

対策は、**境界付近で重みを段階的に変える**ことです。

```cpp
// 親の重みと平均を取ることを繰り返し、境界をなだらかにする。
void BoneMask::Smooth(const Skeleton& skeleton, int steps) {
    for (int pass = 0; pass < steps; ++pass) {
        std::vector<float> next = weights_;
        for (std::size_t i = 0; i < skeleton.BoneCount(); ++i) {
            const BoneIndex bone = static_cast<BoneIndex>(i);
            const BoneIndex parent = skeleton.ParentOf(bone);
            if (parent != kNoParent) {
                next[i] = (weights_[i] + weights_[parent]) * 0.5f;
            }
        }
        weights_ = next;
    }
}
```

実際に試しました。`root → spine → chest → arm → hand` と `root → hip → leg` の 7 ボーンで、`chest` 以下に 1.0 を設定し、2 回スムージングした結果です。

```
ボーン :  root  spine  chest   arm   hand    hip    leg
重み   : 0.000  0.000  0.250  0.750  1.000  0.000  0.000
```

境界がなだらかになりました。胸で 25%、腕で 75%、手で 100%。

**ただし、これには副作用があります。**

**マスクが内側にずれました。** `chest` は元々 1.0 だったのに 0.25 になっています。「胸から先を手振りにする」つもりが、実際には「手だけが手振り、胸はほぼ走りのまま」になっています。

**親方向へは広がりません。** `spine` は 0.0 のままです。平滑化が親 → 子の方向にしか働かないためです。

つまりこのスムージングは、**「境界をなだらかにする」というより「マスクの範囲を狭めながらなだらかにする」**ものです。

実務での対処は 2 つあります。

**① マスクを 1 段上から設定してからスムージングする。** `chest` ではなく `spine` から 1.0 にして平滑化すれば、`chest` が 0.75 程度になり、意図に近づきます。

**② アーティストが直接重みを指定する。** ツール上でボーンごとに 0.0 / 0.3 / 0.7 / 1.0 と手で置く。実際の制作では、これが最も多い方法です。

**本書は ② を主とし、`Smooth` を補助として提供します。** 自動化には限界がある、という正直な位置づけです。

## 41.5　加算ブレンドとの組み合わせ

前章の加算ブレンドは、**マスクと組み合わせると本領を発揮します**。

```cpp
// 上半身だけに被弾リアクションを乗せる
Pose result = locomotionPose;
Pose masked(boneCount);
ApplyAdditive(result, hitAdditive, hitWeight, masked);
BlendPoseMasked(result, masked, upperBodyMask, result);
```

第 40 章のハマりどころで「呼吸が全身に効いてしまう」と書きました。差分クリップに意図しないボーンの値が混ざる問題です。**マスクで範囲を切れば、この問題は消えます。**

もっと効率的には、**加算の重みにマスクを掛ける**形にできます。

```cpp
// マスク付きの加算適用（バッファが 1 本減る）
inline void ApplyAdditiveMasked(const Pose& base, const Pose& additive,
                                float weight, const BoneMask& mask, Pose& out) {
    for (std::size_t i = 0; i < base.Size(); ++i) {
        const BoneIndex bone = static_cast<BoneIndex>(i);
        const float w = weight * mask.Weight(bone);
        if (w <= 0.0f) {
            out[bone] = base[bone];
            continue;
        }
        // 以下、第 40 章の ApplyAdditive と同じ
        const Quat scaled = Nlerp(QuatIdentity(), additive[bone].rotation, w);
        out[bone] = {base[bone].translation + additive[bone].translation * w,
                     scaled * base[bone].rotation,
                     base[bone].scale};
    }
}
```

**重みを掛け合わせるだけ**で済みます。中間バッファが 1 本減るので、第 44 章のブレンドツリーでは意味のある節約になります。

## 41.6　テストを書く

`AnimLib.Tests/BoneMaskTests.cpp`：

```cpp
#include "CppUnitTest.h"

#include "TestSupport/MathAssert.h"
#include "TestSupport/TestRandom.h"
#include "TestSupport/Tolerance.h"

#include "anim/BoneMask.h"

#include <format>

using namespace Microsoft::VisualStudio::CppUnitTestFramework;
using namespace anim;

namespace {

// root ─ spine ─ chest ─ arm ─ hand
//   └─ hip ─ leg
Skeleton MakeBodySkeleton() {
    SkeletonBuilder b;
    b.AddRoot("root");
    b.AddBone("spine", "root");
    b.AddBone("chest", "spine");
    b.AddBone("arm",   "chest");
    b.AddBone("hand",  "arm");
    b.AddBone("hip",   "root");
    b.AddBone("leg",   "hip");
    return b.Build();
}

Pose RandomPose(std::size_t boneCount, anim::test::TestRandom& rng) {
    Pose p(boneCount);
    for (std::size_t i = 0; i < boneCount; ++i) {
        p[static_cast<BoneIndex>(i)] = {rng.NextVec3(2.0f), rng.NextQuat(), {1, 1, 1}};
    }
    return p;
}

}  // namespace

namespace AnimLibTests {

TEST_CLASS(BoneMaskTests) {
public:

    // --- 部分木への設定 -------------------------------------------

    TEST_METHOD(SubtreeIsSelectedCorrectly) {
        const Skeleton s = MakeBodySkeleton();
        BoneMask mask;
        mask.Resize(s.BoneCount());
        mask.SetSubtree(s, 2, 1.0f);      // chest 以下

        anim::test::AssertNear(0.0f, mask.Weight(0));   // root
        anim::test::AssertNear(0.0f, mask.Weight(1));   // spine
        anim::test::AssertNear(1.0f, mask.Weight(2));   // chest
        anim::test::AssertNear(1.0f, mask.Weight(3));   // arm
        anim::test::AssertNear(1.0f, mask.Weight(4));   // hand
        anim::test::AssertNear(0.0f, mask.Weight(5));   // hip
        anim::test::AssertNear(0.0f, mask.Weight(6));   // leg
    }

    TEST_METHOD(RootSubtreeSelectsEverything) {
        const Skeleton s = MakeBodySkeleton();
        BoneMask mask;
        mask.Resize(s.BoneCount());
        mask.SetSubtree(s, 0, 1.0f);
        for (BoneIndex i = 0; i < s.BoneCount(); ++i) {
            anim::test::AssertNear(1.0f, mask.Weight(i));
        }
    }

    TEST_METHOD(LeafSubtreeSelectsOnlyItself) {
        const Skeleton s = MakeBodySkeleton();
        BoneMask mask;
        mask.Resize(s.BoneCount());
        mask.SetSubtree(s, 4, 1.0f);      // hand（葉）
        anim::test::AssertNear(1.0f, mask.Weight(4));
        anim::test::AssertNear(0.0f, mask.Weight(3));
    }

    // --- マスク外はビット単位で不変（41.2 節）--------------------

    TEST_METHOD(MaskedOutBonesAreBitIdentical) {
        const Skeleton s = MakeBodySkeleton();

        const Pose base = RandomPose(s.BoneCount(), rng);

        BoneMask mask;

        Pose out(s.BoneCount());
        BlendPoseMasked(base, overlay, mask, out);

        for (const BoneIndex i : {BoneIndex{0}, BoneIndex{1}, BoneIndex{5}, BoneIndex{6}}) {
            Assert::IsTrue(out[i].translation.x == base[i].translation.x);
            Assert::IsTrue(out[i].translation.y == base[i].translation.y);
            Assert::IsTrue(out[i].translation.z == base[i].translation.z);
            Assert::IsTrue(out[i].rotation.x == base[i].rotation.x);
            Assert::IsTrue(out[i].rotation.w == base[i].rotation.w);
        }
    }

    TEST_METHOD(FullyMaskedBonesComeFromTheOverlay) {
        const Skeleton s = MakeBodySkeleton();
        anim::test::TestRandom rng;
        const Pose base = RandomPose(s.BoneCount(), rng);
        const Pose overlay = RandomPose(s.BoneCount(), rng);

        BoneMask mask;
        mask.Resize(s.BoneCount());

        Pose out(s.BoneCount());
        BlendPoseMasked(base, overlay, mask, out);

        for (const BoneIndex i : {BoneIndex{2}, BoneIndex{3}, BoneIndex{4}}) {
            Assert::IsTrue(out[i].translation.x == overlay[i].translation.x);
            Assert::IsTrue(out[i].rotation.w == overlay[i].rotation.w);
        }
    }

    // 中間の重みでは混ざること
    TEST_METHOD(PartialWeightsBlend) {
        const Skeleton s = MakeBodySkeleton();
        Pose base(s.BoneCount());
        Pose overlay(s.BoneCount());
        for (BoneIndex i = 0; i < s.BoneCount(); ++i) {
            base[i] = {{0, 0, 0}, QuatIdentity(), {1, 1, 1}};
            overlay[i] = {{0, 1, 0}, QuatIdentity(), {1, 1, 1}};
        }

        BoneMask mask;
        mask.Resize(s.BoneCount());
        mask.Set(3, 0.25f);

        Pose out(s.BoneCount());
        BlendPoseMasked(base, overlay, mask, out);
        anim::test::AssertNear(0.25f, out[3].translation.y, test::kEpsPos);
    }

    // --- スムージング（41.4 節）----------------------------------

    TEST_METHOD(SmoothingCreatesAGradientBelowTheBoundary) {
        const Skeleton s = MakeBodySkeleton();
        BoneMask mask;
        mask.Resize(s.BoneCount());
        mask.SetSubtree(s, 2, 1.0f);
        mask.Smooth(s, 2);

        std::wstring line;
        for (BoneIndex i = 0; i < s.BoneCount(); ++i) {

        mask.Resize(s.BoneCount());

    TEST_METHOD(SmoothingShrinksTheMask) {
        const Skeleton s = MakeBodySkeleton();
        BoneMask before;
        before.Resize(s.BoneCount());
        before.SetSubtree(s, 2, 1.0f);

        BoneMask after = before;
        after.Smooth(s, 2);

        // 元は 1.0 だった chest が下がっている
        Assert::IsTrue(after.Weight(2) < before.Weight(2));
    }

    // 全部同じ値なら、平滑化しても変わらない
    TEST_METHOD(SmoothingIsIdempotentOnUniformMasks) {
        const Skeleton s = MakeBodySkeleton();
        BoneMask mask;
        mask.Resize(s.BoneCount());
        mask.Fill(0.7f);
        mask.Smooth(s, 3);
        for (BoneIndex i = 0; i < s.BoneCount(); ++i) {
            anim::test::AssertNear(0.7f, mask.Weight(i), test::kEpsDir);
        }
    }

    // --- 加算との組み合わせ（41.5 節）----------------------------

    TEST_METHOD(MaskedAdditiveMatchesMaskThenAdditive) {
        const Skeleton s = MakeBodySkeleton();
        anim::test::TestRandom rng;
        const Pose base = RandomPose(s.BoneCount(), rng);
        Pose additive(s.BoneCount());
        for (BoneIndex i = 0; i < s.BoneCount(); ++i) {
            additive[i] = {{0, 0.1f, 0}, MakeQuatAxisAngle({0, 0, 1}, 0.1f), {1, 1, 1}};
        }

        BoneMask mask;
        mask.Resize(s.BoneCount());
        mask.SetSubtree(s, 2, 1.0f);
        mask.Set(1, 0.5f);   // 部分的な重みも混ぜる

        // ① 加算してからマスク
        Pose viaTwoSteps(s.BoneCount());
        Pose applied(s.BoneCount());
        ApplyAdditive(base, additive, 0.6f, applied);
        BlendPoseMasked(base, applied, mask, viaTwoSteps);

        // ② マスク付き加算
        Pose viaOneStep(s.BoneCount());
        ApplyAdditiveMasked(base, additive, 0.6f, mask, viaOneStep);

        // 平行移動は厳密に一致する（線形なので）
        for (BoneIndex i = 0; i < s.BoneCount(); ++i) {
            anim::test::AssertNear(viaTwoSteps[i].translation, viaOneStep[i].translation,

        }
    }

    // --- 境界の連続性 ---------------------------------------------

    // 重みを 0 → 1 へ連続的に動かしたとき、姿勢も連続に変わること
    TEST_METHOD(PoseVariesContinuouslyWithMaskWeight) {
        const Skeleton s = MakeBodySkeleton();
        anim::test::TestRandom rng;
        const Pose base = RandomPose(s.BoneCount(), rng);
        const Pose overlay = RandomPose(s.BoneCount(), rng);

        BoneMask mask;
        mask.Resize(s.BoneCount());

        Pose previous(s.BoneCount());
        Pose current(s.BoneCount());
        mask.Set(3, 0.0f);
        BlendPoseMasked(base, overlay, mask, previous);

        float worstJump = 0.0f;
        for (int i = 1; i <= 1000; ++i) {
            mask.Set(3, static_cast<float>(i) / 1000.0f);
            BlendPoseMasked(base, overlay, mask, current);
            worstJump = std::fmax(worstJump,
                Length(current[3].translation - previous[3].translation));
            previous[3] = current[3];
        }
        // 4 m 離れた姿勢を 1000 分割 → 1 ステップは 4 mm 程度
        Assert::IsTrue(worstJump < 0.02f);
    }
};

}  // namespace AnimLibTests
```

`MaskedOutBonesAreBitIdentical` が、41.2 節の設計を守る番人です。`==` による**厳密な比較**を使っているのが要点で、`BlendTransform` を無条件に通す実装に戻すと落ちます。

`SmoothingShrinksTheMask` と `SmoothingDoesNotSpreadUpward` は、**スムージングの限界を仕様として記録**するテストです。「思ったとおりに動かない」ことを、あらかじめ書き留めておきます。

`PoseVariesContinuouslyWithMaskWeight` は、重みを連続的に動かしたときに姿勢が飛ばないことの確認です。重み 0 と 1 で特別扱いしている（41.2 節）ので、**境界で不連続になっていないか**を検査する意味があります。

## 41.7　つまずきやすいところ

**腰から上が不自然に折れる**
マスクの境界が急峻です。スムージングするか、アーティストに重みを調整してもらってください（41.4 節）。

**マスク外のボーンがわずかに変化する**
重み 0 のときに `BlendTransform` を通しています。分岐を入れてください（41.2 節）。

**スムージングしたら効果が弱くなった**
マスクが内側に狭まっています（41.4 節）。1 段上のボーンから設定してください。

**マスクの設定が面倒**
`PropagateFromRoots` 方式にすると、ボーン 1 本の指定で部分木が決まります（41.3 節）。

**ボーン名でマスクを定義したい**
セットアップ時に `FindBone` で解決してください（第 13 章）。ランタイムで名前を引くのは設計の誤りです。

**マスクとスケルトンのボーン数が合わない**
`ANIM_ASSERT` で落ちます。モデルを差し替えたらマスクも作り直してください。第 37 章の焼き込みでは、マスクもアセットに含めるのが実務的です。

**加算とマスクの順序で結果が変わる**
`ApplyAdditiveMasked`（重みを掛け合わせる方式）を使えば、順序の問題自体が消えます（41.5 節）。

## この章のまとめ

- ボーンマスクは、**ブレンドの効果をボーンごとに制御する**仕組み。「走りながら手を振る」を 2 本のクリップで実現できる。
- **重み 0 と 1 は特別扱いして、ビット単位で不変にする。** 性能ではなく**性質の保証**のため。`Nlerp` を通すと `1e-7` の変化が入り、「マスク外は一切変化しない」という保証が失われる。
- 部分木への設定は、**第 13 章の不変条件（親は自分より前）**のおかげで `root + 1` から 1 パスで済む。
- 素朴なマスクは**境界で姿勢が急に切り替わる**。人体としてありえない曲がり方になる。
- スムージングで緩和できるが、**副作用がある** ―― マスクが**内側に狭まり**、**親方向へは広がらない**。実測で `chest` が 1.0 → 0.25 になった。
- だから**アーティストが直接重みを指定する**のが実務では主流。自動化には限界がある。
- **加算ブレンドとマスクを組み合わせる**と、第 40 章の「差分が全身に効く」問題が消える。重みを掛け合わせる形にすれば、中間バッファも 1 本減る。

次章から 2 章、パラメータで連続的にブレンドする仕組みを作ります。
