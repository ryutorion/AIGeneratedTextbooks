# 第 18 章　リニアブレンドスキニング

**この章で作るもの**：`SkinPositionLBS` ―― 頂点を実際に変形する関数。本書のクライマックスその 1 です。ここまで 17 章かけて積み上げてきたものが、ようやく 1 つの式に集約されます。

---

## 18.1　式

頂点 `p` が、ボーン `j₀ … j₃` にウェイト `w₀ … w₃` で属しているとします。第 16 章で作ったパレットを使って、

```
p' = Σ  w_k · ( palette[j_k] · p )
     k
```

**これだけです。**

日本語にすると、「**それぞれのボーンが単独で頂点をどこへ動かすかを計算し、その結果をウェイトで加重平均する**」。

`palette[j_k] · p` の部分は、第 15 章で導いたとおり「バインドポーズの座標をボーンのローカル空間へ引き戻し、現在の姿勢へ送る」という処理です。それをボーンごとに行い、混ぜる。**この「混ぜる」が線形（linear）だから、リニアブレンドスキニング**と呼ばれます。

そして、この「線形に混ぜる」という素朴さが、第 21 章で扱う破綻の原因でもあります。今はまだ、素直に実装します。

---

## 18.2　2 つの等価な書き方

上の式は、次のように変形できます。

```
p' = Σ w_k (M_k · p)  =  ( Σ w_k M_k ) · p
```

行列とベクトルの積は行列について線形なので、**「点を混ぜる」のと「行列を混ぜてから 1 回変換する」のは、数学的に同じ**です。

どちらで実装すべきでしょうか。演算量を数えてみます。影響ボーン 4 本、位置だけを変換する場合:

| 方式 | 演算 |
| --- | --- |
| 点を混ぜる | 変換 4 回（各 9 乗算 3 加算）+ 加重和（12 乗算） |
| 行列を混ぜる | 行列の加重和（4 × 12 = 48 乗算）+ 変換 1 回 |

**位置だけなら「点を混ぜる」ほうが軽い。** しかし位置・法線・接線の 3 つを変換するなら、行列を 1 回混ぜて 3 回使い回せるので逆転します。

実測しました（10 万頂点、影響 4 本）。

| 変換する属性 | 点を混ぜる | 行列を混ぜる |
| --- | --- | --- |
| 位置のみ | **1.557 ms** | 1.887 ms |
| 位置 + 法線 + 接線 | 3.674 ms | **2.123 ms** |

3 属性なら、行列を混ぜるほうが **1.73 倍**速い。これが、**GPU のスキニングシェーダがほぼ例外なく「行列を混ぜる」形で書かれている理由**です（第 58 章）。

本書は**両方を実装します**。片方だけあれば足りるのですが、2 つの独立した実装が同じ答えを出すことを確かめられるからです。実測では最大の食い違いが `4.83e-07`。第 4 章で決めた `kEpsPos`（1.0e-4）の 200 分の 1 で、十分に一致しています。

## 18.3　実装

`AnimLib/include/anim/Skinning.h`：

```cpp
#pragma once

#include "anim/Mat4.h"
#include "anim/SkinnedMesh.h"

#include <span>

namespace anim {

// 影響ボーンのパレット行列をウェイトで加重平均する。
// 位置・法線・接線をまとめて変換するときはこちらが速い。
[[nodiscard]] inline Mat4 BlendSkinMatrix(const SkinnedVertex& v,
                                          std::span<const Mat4> palette) {
    Mat4 result{};   // ゼロ行列から始める（Identity ではない）
    for (int k = 0; k < kMaxInfluences; ++k) {
        const float w = v.weights[k];
        if (w == 0.0f) {
            continue;
        }
        const Mat4& m = palette[v.joints[k]];
        for (int i = 0; i < 4; ++i) {
            for (int j = 0; j < 4; ++j) {
                result.m[i][j] += m.m[i][j] * w;
            }
        }
    }
    return result;
}

// 位置だけを変形する。参照実装。
[[nodiscard]] inline Vec3 SkinPositionLBS(const SkinnedVertex& v,
                                          std::span<const Mat4> palette) {
    Vec3 p{0.0f, 0.0f, 0.0f};
    for (int k = 0; k < kMaxInfluences; ++k) {
        const float w = v.weights[k];
        if (w == 0.0f) {
            continue;
        }
        p = p + w * TransformPoint(palette[v.joints[k]], v.position);
    }
    return p;
}

// メッシュ全体を変形する。
void SkinMeshLBS(const SkinnedMesh& mesh,
                 std::span<const Mat4> palette,
                 std::span<Vec3> outPositions);

}  // namespace anim
```

`Mat4 result{}` が**ゼロ行列**であることが重要です。第 6 章のハマりどころで「`Mat4{}` は単位行列ではない」と書きましたが、ここではゼロ行列こそが正しい初期値です。加重平均を積み上げていくのですから。

そしてウェイトの合計が 1 なら、加重平均された行列の最下行は `(0,0,0,1)` のままになります。アフィン変換であり続ける、ということです。**ウェイトの合計が 1 でないと、ここが `(0,0,0,0.98)` のようになり、変換全体が壊れます。** 第 17 章で正規化にこだわった理由です。

```cpp
void SkinMeshLBS(const SkinnedMesh& mesh,
                 std::span<const Mat4> palette,
                 std::span<Vec3> outPositions) {
    ANIM_ASSERT(outPositions.size() == mesh.vertices.size());
    for (std::size_t i = 0; i < mesh.vertices.size(); ++i) {
        outPositions[i] = SkinPositionLBS(mesh.vertices[i], palette);
    }
}
```

**出力バッファは呼び出し側が持つ**という方針は、第 14 章から変わりません。10 万頂点の `Vec3` は 1.2 MB。毎フレーム確保するものではありません。

```cpp
SkinnedModel model;

```

第 1 章で示したパイプラインの ③⑤⑥ が、**3 行**になりました。

```
① クリップをサンプル    ← 第 V 部
② ブレンド              ← 第 VII 部
③ 階層を解く            ← ✅
④ IK で補正             ← 第 VIII 部
⑤ パレットを作る        ← ✅
⑥ 頂点を変形            ← ✅ この章
```

**キャラクターが動くのに必要な最小限の骨格が、これで完成しました。** 残りの部で足していくのは、「①どこから姿勢を持ってくるか」「②どう混ぜるか」「④どう補正するか」、そして「どう速くするか」です。変形そのものは、この 1 行で終わりです。

## 18.5　テストを書く

`AnimLib.Tests/SkinningTests.cpp`：

```cpp
#include "CppUnitTest.h"

#include "TestSupport/MathAssert.h"
#include "TestSupport/MeshSupport.h"
#include "TestSupport/SkeletonSupport.h"
#include "TestSupport/TestRandom.h"
#include "TestSupport/Tolerance.h"

#include "anim/Skinning.h"
#include "anim/SkinnedCharacter.h"

#include <numbers>

using namespace Microsoft::VisualStudio::CppUnitTestFramework;
using namespace anim;
using anim::test::AssertNear;

namespace {

constexpr float kPi = std::numbers::pi_v<float>;

// 円柱に対応する 2 ボーンのスケルトン：
// root は原点、joint は x = 0.5（円柱の中央）
SkinnedModel MakeCylinderModel(float jointX = 0.5f) {
    SkeletonBuilder b;
    b.AddRoot("root");
    b.AddBone("joint", "root", Transform{{jointX, 0, 0}, QuatIdentity(), {1, 1, 1}});

    SkinnedModel model;
    model.skeleton = b.Build();
    model.inverseBind.resize(model.skeleton.BoneCount());
    ComputeInverseBindMatrices(model.skeleton, model.skeleton.RestLocals(),
                               model.inverseBind);
    return model;
}

}  // namespace

namespace AnimLibTests {

TEST_CLASS(SkinningTests) {
public:

    // --- 最重要：バインドポーズで無変形 ---------------------------

    TEST_METHOD(BindPoseProducesNoDeformation) {
        const SkinnedModel model = MakeCylinderModel();
        const SkinnedMesh mesh = test::MakeCylinder(24, 24, 1.0f, 0.15f);

        SkinnedCharacter character(model);
        character.Update(model);

        std::vector<Vec3> out(mesh.vertices.size());
        SkinMeshLBS(mesh, character.Palette().Matrices(), out);

        for (std::size_t i = 0; i < mesh.vertices.size(); ++i) {
            AssertNear(mesh.vertices[i].position, out[i], test::kEpsPos);
        }
    }

    // --- 100% 1 本のボーンなら剛体変換 ----------------------------

    TEST_METHOD(SingleBoneVertexFollowsRigidTransform) {
        const SkinnedModel model = MakeCylinderModel();
        const SkinnedMesh mesh = test::MakeCylinder(24, 24, 1.0f, 0.15f);

        SkinnedCharacter character(model);
        character.LocalPose()[1].rotation = MakeQuatAxisAngle({0, 0, 1}, 0.7f);
        character.Update(model);
        const std::span<const Mat4> palette = character.Palette().Matrices();

        for (const SkinnedVertex& v : mesh.vertices) {
            // ウェイトが 1 本に集中している頂点だけを見る
            int single = -1;
            for (int k = 0; k < kMaxInfluences; ++k) {
                if (v.weights[k] == 1.0f) { single = k; }
            }
            if (single < 0) { continue; }

            AssertNear(TransformPoint(palette[v.joints[single]], v.position),
                       SkinPositionLBS(v, palette), test::kEpsPos);
        }
    }

    // --- 2 つの実装の一致（18.2 節）------------------------------

    TEST_METHOD(BlendingPointsMatchesBlendingMatrices) {
        const SkinnedModel model = MakeCylinderModel();
        const SkinnedMesh mesh = test::MakeCylinder(24, 24, 1.0f, 0.15f);

        SkinnedCharacter character(model);
        character.LocalPose()[1].rotation = MakeQuatAxisAngle({1, 2, 3}, 1.1f);
        character.Update(model);
        const std::span<const Mat4> palette = character.Palette().Matrices();

        for (const SkinnedVertex& v : mesh.vertices) {
            AssertNear(SkinPositionLBS(v, palette),
                       TransformPoint(BlendSkinMatrix(v, palette), v.position),
                       test::kEpsPos);
        }
    }

    // --- 50:50 は 2 つの変換結果の中点 ----------------------------

    TEST_METHOD(FiftyFiftyIsTheMidpointOfBothTransforms) {
        const SkinnedModel model = MakeCylinderModel();
        SkinnedCharacter character(model);
        character.LocalPose()[1].rotation = MakeQuatAxisAngle({0, 0, 1}, 0.9f);
        character.Update(model);
        const std::span<const Mat4> palette = character.Palette().Matrices();

        SkinnedVertex v{};
        v.position = {0.5f, 0.15f, 0.0f};
        v.joints[0] = 0;  v.weights[0] = 0.5f;
        v.joints[1] = 1;  v.weights[1] = 0.5f;

        const Vec3 expected = 0.5f * TransformPoint(palette[0], v.position)
                            + 0.5f * TransformPoint(palette[1], v.position);
        AssertNear(expected, SkinPositionLBS(v, palette), test::kEpsPos);
    }

    // --- 性質 -----------------------------------------------------

    // すべてのボーンが同じ変換なら、ウェイトによらず剛体変換になる
    TEST_METHOD(IdenticalBonesGiveRigidTransformRegardlessOfWeights) {
        const Mat4 m = MakeTranslation({1, 2, 3})
                     * ToMat4(MakeQuatAxisAngle({1, 1, 0}, 0.6f));
        const std::vector<Mat4> palette{m, m, m, m};

        test::TestRandom rng;
        for (int trial = 0; trial < 500; ++trial) {
            SkinnedVertex v{};
            v.position = rng.NextVec3(2.0f);
            float sum = 0.0f;
            for (int k = 0; k < kMaxInfluences; ++k) {
                v.joints[k] = static_cast<BoneIndex>(k);
                v.weights[k] = rng.NextUnit();
                sum += v.weights[k];
            }
            for (int k = 0; k < kMaxInfluences; ++k) { v.weights[k] /= sum; }

            AssertNear(TransformPoint(m, v.position),
                       SkinPositionLBS(v, palette), test::kEpsPos);
        }
    }

    // ルートを動かすと、変形後のメッシュ全体が同じだけ平行移動する
    TEST_METHOD(MovingRootTranslatesTheWholeMesh) {
        const SkinnedModel model = MakeCylinderModel();
        const SkinnedMesh mesh = test::MakeCylinder(12, 12, 1.0f, 0.15f);

        SkinnedCharacter a(model);
        a.LocalPose()[1].rotation = MakeQuatAxisAngle({0, 0, 1}, 0.5f);
        a.Update(model);

        SkinnedCharacter b(model);
        b.LocalPose()[1].rotation = MakeQuatAxisAngle({0, 0, 1}, 0.5f);
        const Vec3 offset{7.0f, -2.0f, 3.0f};
        b.LocalPose()[0].translation = offset;
        b.Update(model);

        std::vector<Vec3> outA(mesh.vertices.size());
        std::vector<Vec3> outB(mesh.vertices.size());
        SkinMeshLBS(mesh, a.Palette().Matrices(), outA);
        SkinMeshLBS(mesh, b.Palette().Matrices(), outB);

        for (std::size_t i = 0; i < outA.size(); ++i) {
            AssertNear(outA[i] + offset, outB[i], test::kEpsPos);
        }
    }

    // ウェイトの合計が 1 でないと、メッシュが縮む（仕様の記録）
    TEST_METHOD(UnnormalizedWeightsShrinkTheMesh) {
        const std::vector<Mat4> palette{Identity(), Identity()};

        SkinnedVertex v{};
        v.position = {1.0f, 2.0f, 3.0f};
        v.joints[0] = 0;  v.weights[0] = 0.5f;
        v.joints[1] = 1;  v.weights[1] = 0.4f;   // 合計 0.9

        // 恒等変換のはずが、10% 原点に寄る
        AssertNear(Vec3{0.9f, 1.8f, 2.7f}, SkinPositionLBS(v, palette), test::kEpsPos);
    }
};

}  // namespace AnimLibTests
```

3 つ補足します。

**`IdenticalBonesGiveRigidTransformRegardlessOfWeights`** は、性質テストとして非常に強力です。すべてのパレット行列が同じなら、ウェイトが何であれ加重平均は元の行列に戻るはずです。ウェイトの扱い、インデックスの参照、加重和 ―― どれか 1 つでも間違っていれば落ちます。**しかも入力をランダムにできる**ので、特定の値で偶然通ることがありません。

**`UnnormalizedWeightsShrinkTheMesh`** は、第 11 章の非一様スケールや第 15 章のレスト／バインド取り違えと同じく、**「間違えたらどうなるか」を仕様として残す**タイプです。「モデルがなんとなく痩せている」という症状に出会ったとき、このテストが原因を思い出させます。

**`MovingRootTranslatesTheWholeMesh`** は、第 14 章・第 16 章の同名のテストをメッシュのレベルまで持ち上げたものです。同じ性質を、パイプラインの各段で確かめています。段ごとに検査しておくと、崩れたときにどこで崩れたかがすぐ分かります。

## 18.6　つまずきやすいところ

**メッシュが原点に潰れる、または一部が原点に向かって伸びる**
ウェイトの合計が 0 の頂点があります（第 17 章）。あるいは `Mat4 result{}` を `Identity()` にしていて、加重平均に単位行列が混ざっています。

**メッシュ全体が少し小さい／大きい**
ウェイトの合計が 1 でありません。第 17 章の正規化を確認してください。

**ボーンを動かしていないのにメッシュが変形する**
パレットがバインドポーズで単位行列になっていません。第 16 章のテストに戻ってください。**第 IV 部のバグの半分は、実は第 III 部の問題です。**

**メッシュの一部だけが取り残される／飛んでいく**
ボーンインデックスが間違っています。円柱の場合、ウェイト 0 の枠に入っている `joints[k]` が範囲外だと、`palette[j]` が範囲外アクセスになります。ウェイト 0 なら `continue` するのでこの実装では安全ですが、**分岐を消した最適化版（第 20 章）や GPU 版（第 58 章）では実際に読みに行きます**。第 17 章で 0 埋めした理由です。

**変形結果が毎回わずかに違う**
`std::vector` の中身が初期化されていない、あるいはウェイトのソート順が非決定的（第 17 章）です。

**遅い**
まだ最適化していません。第 20 章で扱います。この章の実装は**参照実装**であり、正しさの基準としてこの先ずっと残します。

## この章のまとめ

- LBS の式は **`p' = Σ w_k · (palette[j_k] · p)`**。「ボーンごとに変換した結果を、ウェイトで加重平均する」だけ。
- **「点を混ぜる」と「行列を混ぜる」は数学的に同じ。** 位置だけなら前者が速い（1.557 vs 1.887 ms）が、位置+法線+接線なら後者が **1.73 倍**速い（2.123 vs 3.674 ms）。GPU のシェーダが行列を混ぜる形なのはこのため。
- 加重平均の初期値は**ゼロ行列**。ウェイトの合計が 1 だからこそ、結果がアフィン変換であり続ける。
- **これで第 1 章のパイプラインの ③⑤⑥ が完成した。** 変形そのものは 1 行。残りの部で足すのは「どこから姿勢を持ってくるか」「どう混ぜるか」「どう速くするか」。
- **すべてのボーンが同じ変換なら、ウェイトによらず剛体変換になる** ―― この性質テストは、ランダム入力で回せて、実装のあらゆる間違いを捕まえる。
- 「ウェイトの合計が 1 でないと縮む」ことも、**テストとして記録しておく**。

次章では法線を扱います。位置と同じように変形すればよさそうに見えて、そうではありません。
