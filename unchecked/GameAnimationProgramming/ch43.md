# 第 43 章　2D ブレンドスペース

**この章で作るもの**：2 次元のパラメータ（前後 × 左右）でクリップを混ぜる仕組み。**三角形分割**と**重心座標**が主題です。1D では自明だった「どのクリップを混ぜるか」が、2D では自明でなくなります。

---

## 43.1　前後だけでは足りない

前章の 1D ブレンドスペースは、移動速度という 1 つのパラメータを扱いました。しかし実際のキャラクターは、**任意の方向に移動**します。

- 前進、後退
- 左右への横歩き（ストレイフ）
- 斜め移動

これらを 1D で表そうとすると、「移動方向」をもう 1 つのパラメータにする必要があり、結局 2 次元です。

**2D ブレンドスペース**は、パラメータ平面にクリップを配置します。

```
              前 (0, 1)
                 ●
        ●                ●        斜め
   左           待機          右
 (-1,0) ●        ●        ● (1,0)
        ●                ●
                 ●
              後 (0,-1)
```

移動方向を表すベクトル `(x, y)` が現在のパラメータで、そこから 9 つのクリップの重みを決めます。

---

## 43.2　1D の素朴な拡張では足りない

「x 方向と y 方向で別々に 1D ブレンドすればよいのでは」と考えたくなります。**格子状にサンプルが並んでいるなら、それで動きます**（双線形補間）。

しかし、実際のブレンドスペースのサンプルは**格子状ではありません**。上図のように、中心 1 つ + 円周上に 8 つ、という配置が典型です。斜め方向のクリップは、前と右の中間ではなく、**専用に作られた斜め歩き**です。

任意の配置に対応するには、**三角形分割して重心座標を使う**のが標準的な方法です。

---

## 43.3　三角形分割

パラメータ平面上の点を三角形に分割します。**ドロネー三角形分割**が定番で、「細長い三角形ができにくい」という良い性質を持ちます。

実装は**ボウヤー・ワトソン法**です。

```cpp
// AnimLib/include/anim/BlendSpace2D.h

struct BlendTriangle { int a, b, c; };

class BlendSpace2D {
public:
    void AddSample(Vec2 position, const Clip* clip) {
        positions_.push_back(position);
        clips_.push_back(clip);
    }

    // ドロネー三角形分割を行う。セットアップ時に一度だけ。
    void Triangulate();

    void ComputeWeights(Vec2 parameter, std::vector<float>& out) const;

private:
    std::vector<Vec2> positions_;
    std::vector<const Clip*> clips_;
    std::vector<BlendTriangle> triangles_;
};
```

```cpp
void BlendSpace2D::Triangulate() {
    triangles_.clear();
    const std::size_t n = positions_.size();
    if (n < 3) { return; }        // 2 点以下は線分として扱う（43.5 節）

    // ① すべての点を含む巨大な三角形（スーパートライアングル）から始める
    float minX = 1.0e30f, minY = 1.0e30f, maxX = -1.0e30f, maxY = -1.0e30f;
    for (const Vec2& p : positions_) {
        minX = std::fmin(minX, p.x);  minY = std::fmin(minY, p.y);
        maxX = std::fmax(maxX, p.x);  maxY = std::fmax(maxY, p.y);
    }
    const float span = std::fmax(maxX - minX, maxY - minY) + 1.0f;
    const float centerX = (minX + maxX) * 0.5f;
    const float centerY = (minY + maxY) * 0.5f;

    std::vector<Vec2> points = positions_;
    points.push_back({centerX - 20.0f * span, centerY - span});
    points.push_back({centerX,                centerY + 20.0f * span});
    points.push_back({centerX + 20.0f * span, centerY - span});

    std::vector<BlendTriangle> working{
        {static_cast<int>(n), static_cast<int>(n) + 1, static_cast<int>(n) + 2}};

    // ② 点を 1 つずつ追加し、外接円に含む三角形を壊して張り直す
    for (std::size_t i = 0; i < n; ++i) {
        std::vector<std::pair<int, int>> edges;
        std::vector<BlendTriangle> keep;

        for (const BlendTriangle& t : working) {
            if (IsInsideCircumcircle(points, t, points[i])) {
                edges.push_back({t.a, t.b});
                edges.push_back({t.b, t.c});
                edges.push_back({t.c, t.a});
            } else {
                keep.push_back(t);
            }
        }
        // 壊した三角形どうしで共有していた辺は、内部の辺なので捨てる
        for (std::size_t e = 0; e < edges.size(); ++e) {
            bool shared = false;
            for (std::size_t f = 0; f < edges.size(); ++f) {
                if (e == f) { continue; }
                if ((edges[e].first == edges[f].second && edges[e].second == edges[f].first)
                 || (edges[e].first == edges[f].first && edges[e].second == edges[f].second)) {
                    shared = true;
                    break;
                }
            }
            if (!shared) {
                keep.push_back({edges[e].first, edges[e].second, static_cast<int>(i)});
            }
        }
        working = keep;
    }

    // ③ スーパートライアングルの頂点を含む三角形を捨てる
    for (const BlendTriangle& t : working) {
        if (t.a < static_cast<int>(n) && t.b < static_cast<int>(n)
                                      && t.c < static_cast<int>(n)) {
            triangles_.push_back(t);
        }
    }
}
```

外接円の判定は、**行列式**で行います。

```cpp
// 点 p が三角形 t の外接円の内側にあるか。
// 巻き方に依存するので、向きを見て符号を反転する。
[[nodiscard]] inline bool IsInsideCircumcircle(std::span<const Vec2> points,
                                               const BlendTriangle& t, Vec2 p) {
    const Vec2 a = points[t.a];
    const Vec2 b = points[t.b];
    const Vec2 c = points[t.c];

    // 誤差に敏感なので double で計算する
    const double ax = a.x - p.x, ay = a.y - p.y;
    const double bx = b.x - p.x, by = b.y - p.y;
    const double cx = c.x - p.x, cy = c.y - p.y;

    const double determinant =
          (ax*ax + ay*ay) * (bx*cy - cx*by)
        - (bx*bx + by*by) * (ax*cy - cx*ay)
        + (cx*cx + cy*cy) * (ax*by - bx*ay);

    const double orientation = Cross2(Sub2(b, a), Sub2(c, a));
    return (orientation > 0.0) ? (determinant > 0.0) : (determinant < 0.0);
}
```

**`double` で計算している**のが重要です。この判定は「点が円周上にあるか」という境界に極めて敏感で、`float` では分割が壊れる（三角形が重なる、穴が開く）ことがあります。第 4 章で決めた「誤差そのものを扱うコードは `double`」の適用です。

三角形分割は**セットアップ時に一度だけ**行います。毎フレーム走るものではないので、`double` のコストも O(n²) の素朴な実装も問題になりません。

## 43.4　重心座標

三角形が決まれば、重みは**重心座標**で求まります。

三角形 `ABC` の内部の点 `P` に対して、

```
wa = 面積(PBC) / 面積(ABC)
wb = 面積(PCA) / 面積(ABC)
wc = 面積(PAB) / 面積(ABC)
```

3 つの重みは、常に `wa + wb + wc = 1` を満たします。**これは代数的な恒等式**であり、誤差を除けば厳密に成り立ちます。

```cpp
void BlendSpace2D::ComputeWeights(Vec2 parameter, std::vector<float>& out) const {
    out.assign(positions_.size(), 0.0f);
    if (positions_.empty()) { return; }
    if (positions_.size() == 1) { out[0] = 1.0f; return; }

    if (positions_.size() == 2 || triangles_.empty()) {
        ProjectOntoSegment(parameter, out);      // 43.5 節
        return;
    }

    // 内包する三角形を探す
    for (const BlendTriangle& t : triangles_) {
        const Vec2 a = positions_[t.a];
        const Vec2 b = positions_[t.b];
        const Vec2 c = positions_[t.c];

        const float area = Cross2(Sub2(b, a), Sub2(c, a));
        if (std::fabs(area) < 1.0e-12f) { continue; }   // 潰れた三角形

        const float wa = Cross2(Sub2(b, parameter), Sub2(c, parameter)) / area;
        const float wb = Cross2(Sub2(c, parameter), Sub2(a, parameter)) / area;
        const float wc = Cross2(Sub2(a, parameter), Sub2(b, parameter)) / area;

        // わずかな負の値は誤差なので許容する
        if (wa >= -1.0e-5f && wb >= -1.0e-5f && wc >= -1.0e-5f) {
            out[t.a] += wa;
            out[t.b] += wb;
            out[t.c] += wc;
            return;
        }
    }

    ProjectOntoNearestEdge(parameter, out);      // 43.5 節
}
```

**`+=` を使っている**のは、同じサンプルが複数の三角形に属するためです（ここでは 1 つの三角形しか使わないので実質 `=` ですが、後述の拡張で効きます）。

**判定に `-1.0e-5f` の余裕を持たせている**のは、三角形の辺の上にある点で、どちらの三角形にも属さないという状況を避けるためです。厳密に `>= 0` にすると、辺の上で重みがすべて 0 になる瞬間が生じます。

## 43.5　凸包の外

パラメータが**サンプルの外側**に出たらどうするか。1D ならクランプで済みましたが、2D では「どこにクランプするか」が自明ではありません。

本書は、**最も近い辺に射影する**方式を採ります。

```cpp
void BlendSpace2D::ProjectOntoNearestEdge(Vec2 parameter, std::vector<float>& out) const {
    float bestDistanceSquared = 1.0e30f;
    int bestFrom = 0;
    int bestTo = 0;
    float bestT = 0.0f;

    for (const BlendTriangle& t : triangles_) {
        const int edges[3][2] = {{t.a, t.b}, {t.b, t.c}, {t.c, t.a}};
        for (const auto& edge : edges) {
            const Vec2 a = positions_[edge[0]];
            const Vec2 b = positions_[edge[1]];
            const Vec2 ab = Sub2(b, a);
            const Vec2 ap = Sub2(parameter, a);

            const float lengthSquared = ab.x * ab.x + ab.y * ab.y;
            float t01 = (lengthSquared > 0.0f)
                      ? (ap.x * ab.x + ap.y * ab.y) / lengthSquared
                      : 0.0f;
            t01 = std::fmin(1.0f, std::fmax(0.0f, t01));

            const Vec2 projected{a.x + ab.x * t01, a.y + ab.y * t01};
            const float distanceSquared =
                (projected.x - parameter.x) * (projected.x - parameter.x)
              + (projected.y - parameter.y) * (projected.y - parameter.y);

            if (distanceSquared < bestDistanceSquared) {
                bestDistanceSquared = distanceSquared;
                bestFrom = edge[0];
                bestTo = edge[1];
                bestT = t01;
            }
        }
    }
    out[bestFrom] = 1.0f - bestT;
    out[bestTo] = bestT;
}
```

内部の辺も候補に入れているので厳密には最適ではありませんが、**凸包の外側の点に対しては、必ず境界の辺が最も近くなる**ので結果は正しくなります。

この方式なら、**外側でも重みの合計は 1** です。「移動速度が想定より速い」といった状況で、アニメーションが消えたり壊れたりしません。

## 43.6　実測

9 点（中心 + 円周 8 方向）で三角形分割し、**ランダムな 20,000 点**で重みを計算しました。

| 項目 | 結果 |
| --- | --- |
| 生成された三角形 | 8 個 |
| サンプル点での重み | すべて厳密に 1.0 |
| `|Σw − 1|` の最大値 | **2.38e-07** |
| 負の重み | なし |
| 凸包内での非ゼロ重みの個数 | **3 個以下** |

**重みの合計が 1 からずれる量が `2.4e-07`。** これは `float` の丸め誤差そのもので、重心座標が代数的な恒等式であることの裏づけです。

**非ゼロが 3 個以下**というのも重要です。ブレンドのコストが、サンプル数によらず一定に保たれます。100 個のサンプルを持つブレンドスペースでも、毎フレーム混ぜるのは 3 つだけです。

> **なぜ 8 三角形なのか**
> 中心 1 点 + 円周 8 点で、中心から各方向へ扇形に分割されるので 8 三角形。ドロネー分割は「外接円に他の点を含まない」という条件を満たす分割で、この配置では扇形分割がそれにあたります。**点の数と三角形の数の関係は `2n − 2 − h`**（`h` は凸包上の点の数）で、`n = 9`, `h = 8` なら `2×9 − 2 − 8 = 8`。実測と一致します。

## 43.7　時刻の同期

第 42 章と同じく、**位相の同期が必要**です。実装も同じで、混合された周期で位相を進め、各クリップの長さを掛けて時刻にします。

2D では、混ぜるクリップが 3 つになるだけです。

```cpp
float blendedDuration = 0.0f;
float totalWeight = 0.0f;
for (std::size_t k = 0; k < weights_.size(); ++k) {
    if (weights_[k] <= 0.0f) { continue; }
    blendedDuration += space_->ClipAt(k)->Duration() * weights_[k];
    totalWeight += weights_[k];
}
```

**前歩きと横歩きで、1 歩の周期が違う**ことは普通にあります。同期しなければ、斜め移動で足が滑ります。

## 43.8　テストを書く

`AnimLib.Tests/BlendSpace2DTests.cpp`：

```cpp
#include "CppUnitTest.h"

#include "TestSupport/MathAssert.h"
#include "TestSupport/TestRandom.h"
#include "TestSupport/Tolerance.h"

#include "anim/BlendSpace2D.h"

#include <format>
#include <numbers>

using namespace Microsoft::VisualStudio::CppUnitTestFramework;
using namespace anim;

namespace {

constexpr float kPi = std::numbers::pi_v<float>;

// 中心 + 円周 8 方向の、典型的な移動ブレンドスペース
BlendSpace2D MakeDirectionalSpace(std::vector<Clip>& storage) {
    storage.resize(9);
    BlendSpace2D space;
    space.AddSample({0.0f, 0.0f}, &storage[0]);
    for (int k = 0; k < 8; ++k) {
        const float angle = 2.0f * kPi * static_cast<float>(k) / 8.0f;
        space.AddSample({std::cos(angle), std::sin(angle)}, &storage[k + 1]);
    }
    space.Triangulate();
    return space;
}

Vec2 SamplePosition(std::size_t index) {
    if (index == 0) { return {0.0f, 0.0f}; }
    const float angle = 2.0f * kPi * static_cast<float>(index - 1) / 8.0f;
    return {std::cos(angle), std::sin(angle)};
}

}  // namespace

namespace AnimLibTests {

TEST_CLASS(BlendSpace2DTests) {
public:

    // --- 三角形分割 -----------------------------------------------

    TEST_METHOD(TriangulationProducesExpectedCount) {
        std::vector<Clip> clips;
        const BlendSpace2D space = MakeDirectionalSpace(clips);
        Logger::WriteMessage(std::format(L"9 points -> {} triangles\n",
                                         space.TriangleCount()).c_str());
        // 2n - 2 - h = 2*9 - 2 - 8 = 8
        Assert::AreEqual(std::size_t{8}, space.TriangleCount());
    }

    TEST_METHOD(TrianglesReferenceValidIndices) {
        std::vector<Clip> clips;
        const BlendSpace2D space = MakeDirectionalSpace(clips);
        for (std::size_t i = 0; i < space.TriangleCount(); ++i) {
            const BlendTriangle& t = space.Triangle(i);
            Assert::IsTrue(t.a >= 0 && t.a < static_cast<int>(space.Size()));
            Assert::IsTrue(t.b >= 0 && t.b < static_cast<int>(space.Size()));
            Assert::IsTrue(t.c >= 0 && t.c < static_cast<int>(space.Size()));
            Assert::IsTrue(t.a != t.b && t.b != t.c && t.a != t.c);
        }
    }

    // --- サンプル点で厳密（この章の中心）--------------------------

    TEST_METHOD(WeightsAreExactAtEachSamplePoint) {
        std::vector<Clip> clips;
        const BlendSpace2D space = MakeDirectionalSpace(clips);

        std::vector<float> w;
        for (std::size_t k = 0; k < space.Size(); ++k) {
            space.ComputeWeights(SamplePosition(k), w);
            anim::test::AssertNear(1.0f, w[k], 1.0e-3f);

            float sum = 0.0f;
            for (const float v : w) { sum += v; }
            anim::test::AssertNear(1.0f, sum, test::kEpsDir);
        }
    }

    // --- 不変条件（43.6 節）--------------------------------------

    TEST_METHOD(WeightsAlwaysSumToOne) {
        std::vector<Clip> clips;
        const BlendSpace2D space = MakeDirectionalSpace(clips);

        anim::test::TestRandom rng;
        std::vector<float> w;
        float worst = 0.0f;
        for (int i = 0; i < 20000; ++i) {
            const Vec2 p{rng.NextRange(-2.0f, 2.0f), rng.NextRange(-2.0f, 2.0f)};
            space.ComputeWeights(p, w);
            float sum = 0.0f;
            for (const float v : w) { sum += v; }
            worst = std::fmax(worst, std::fabs(sum - 1.0f));
        }
        Logger::WriteMessage(std::format(
            L"worst |sum(w) - 1| over 20000 points = {:.3g}\n", worst).c_str());
        Assert::IsTrue(worst < 1.0e-3f);   // 実測 2.38e-07
    }

    TEST_METHOD(WeightsAreNeverNegative) {
        std::vector<Clip> clips;
        const BlendSpace2D space = MakeDirectionalSpace(clips);

        anim::test::TestRandom rng;
        std::vector<float> w;
        for (int i = 0; i < 20000; ++i) {
            const Vec2 p{rng.NextRange(-2.0f, 2.0f), rng.NextRange(-2.0f, 2.0f)};
            space.ComputeWeights(p, w);
            for (const float v : w) {
                Assert::IsTrue(v >= -1.0e-4f);
            }
        }
    }

    // 凸包内では非ゼロが 3 個以下（コストが一定）
    TEST_METHOD(AtMostThreeNonZeroWeightsInsideTheHull) {
        std::vector<Clip> clips;
        const BlendSpace2D space = MakeDirectionalSpace(clips);

        anim::test::TestRandom rng;
        std::vector<float> w;
        for (int i = 0; i < 5000; ++i) {
            const Vec2 p{rng.NextRange(-0.6f, 0.6f), rng.NextRange(-0.6f, 0.6f)};
            space.ComputeWeights(p, w);
            int nonZero = 0;
            for (const float v : w) { if (v > 1.0e-6f) { ++nonZero; } }
            Assert::IsTrue(nonZero <= 3);
        }
    }

    // --- 連続性 ---------------------------------------------------

    TEST_METHOD(WeightsVaryContinuously) {
        std::vector<Clip> clips;
        const BlendSpace2D space = MakeDirectionalSpace(clips);

        std::vector<float> previous;
        std::vector<float> current;
        space.ComputeWeights({-1.5f, 0.13f}, previous);

        float worstJump = 0.0f;
        for (int i = 1; i <= 6000; ++i) {
            // 三角形の境界をいくつも横切る経路
            const float x = -1.5f + 3.0f * static_cast<float>(i) / 6000.0f;
            space.ComputeWeights({x, 0.13f}, current);
            for (std::size_t k = 0; k < current.size(); ++k) {
                worstJump = std::fmax(worstJump, std::fabs(current[k] - previous[k]));
            }
            previous = current;
        }
        Logger::WriteMessage(std::format(
            L"max weight jump across triangle boundaries = {:.6f}\n", worstJump).c_str());
        Assert::IsTrue(worstJump < 0.01f);

    // 円周上を 1 周しても連続であること
    TEST_METHOD(WeightsAreContinuousAroundTheCircle) {
        std::vector<Clip> clips;
        const BlendSpace2D space = MakeDirectionalSpace(clips);

        std::vector<float> previous;
        std::vector<float> current;
        space.ComputeWeights({0.7f, 0.0f}, previous);

        float worstJump = 0.0f;
        for (int i = 1; i <= 3600; ++i) {
            const float angle = 2.0f * kPi * static_cast<float>(i) / 3600.0f;
            space.ComputeWeights({0.7f * std::cos(angle), 0.7f * std::sin(angle)}, current);
            for (std::size_t k = 0; k < current.size(); ++k) {
                worstJump = std::fmax(worstJump, std::fabs(current[k] - previous[k]));
            }
            previous = current;

        Assert::IsTrue(worstJump < 0.01f);

    // --- 凸包の外（43.5 節）--------------------------------------

    TEST_METHOD(OutsideTheHullProjectsOntoTheBoundary) {

        float sum = 0.0f;
        for (const float v : w) { sum += v; }
        anim::test::AssertNear(1.0f, sum, test::kEpsDir);
        // 右のサンプル（index 1、角度 0）が支配的になるはず
        Assert::IsTrue(w[1] > 0.9f);
    }

    TEST_METHOD(FarOutsidePointsStillGiveValidWeights) {
        std::vector<Clip> clips;
        const BlendSpace2D space = MakeDirectionalSpace(clips);

        std::vector<float> w;
        for (const Vec2 p : {Vec2{1000.0f, 1000.0f}, Vec2{-1000.0f, 0.0f},
                             Vec2{0.0f, -1000.0f}}) {
            space.ComputeWeights(p, w);
            float sum = 0.0f;
            for (const float v : w) {
                Assert::IsFalse(std::isnan(v));
                Assert::IsTrue(v >= -1.0e-4f);
                sum += v;

            anim::test::AssertNear(1.0f, sum, test::kEpsDir);
        }
    }

    // --- 退化した配置 ---------------------------------------------

    TEST_METHOD(TwoSamplesBehaveLikeASegment) {
        Clip a, b;
        BlendSpace2D space;
        space.AddSample({0.0f, 0.0f}, &a);
        space.AddSample({2.0f, 0.0f}, &b);
        space.Triangulate();

        std::vector<float> w;
        space.ComputeWeights({1.0f, 0.0f}, w);
        anim::test::AssertNear(0.5f, w[0], test::kEpsDir);
        anim::test::AssertNear(0.5f, w[1], test::kEpsDir);

        space.ComputeWeights({1.0f, 5.0f}, w);   // 線分から離れた点
        float sum = 0.0f;
        for (const float v : w) { sum += v; }
        anim::test::AssertNear(1.0f, sum, test::kEpsDir);
    }

    TEST_METHOD(SingleSampleAlwaysGetsFullWeight) {
        Clip a;
        BlendSpace2D space;
        space.AddSample({1.0f, 2.0f}, &a);
        space.Triangulate();

        std::vector<float> w;
        space.ComputeWeights({-100.0f, 50.0f}, w);
        anim::test::AssertNear(1.0f, w[0]);
    }

    // 一直線に並んだ点でも壊れないこと
    TEST_METHOD(CollinearSamplesDoNotCrash) {
        std::vector<Clip> clips(4);
        BlendSpace2D space;
        for (int k = 0; k < 4; ++k) {
            space.AddSample({static_cast<float>(k), 0.0f}, &clips[k]);
        }
        space.Triangulate();

        std::vector<float> w;
        for (int i = 0; i <= 100; ++i) {
            space.ComputeWeights({static_cast<float>(i) * 0.04f, 0.0f}, w);
            float sum = 0.0f;
            for (const float v : w) {
                Assert::IsFalse(std::isnan(v));
                sum += v;
            }
            anim::test::AssertNear(1.0f, sum, test::kEpsDir);
        }
    }

    // 格子状の配置でも正しく動くこと
    TEST_METHOD(GridLayoutWorks) {
        std::vector<Clip> clips(9);
        BlendSpace2D space;
        int index = 0;
        for (int y = -1; y <= 1; ++y) {
            for (int x = -1; x <= 1; ++x) {
                space.AddSample({static_cast<float>(x), static_cast<float>(y)},
                                &clips[index++]);
            }
        }
        space.Triangulate();

        anim::test::TestRandom rng;
        std::vector<float> w;
        for (int i = 0; i < 5000; ++i) {
            const Vec2 p{rng.NextRange(-1.0f, 1.0f), rng.NextRange(-1.0f, 1.0f)};
            space.ComputeWeights(p, w);
            float sum = 0.0f;
            for (const float v : w) { sum += v; }
            anim::test::AssertNear(1.0f, sum, test::kEpsDir);
        }
    }

```

`WeightsAlwaysSumToOne` は、**20,000 点のランダム入力**で不変条件を検査しています。三角形分割に穴があれば、その領域で凸包外の経路に落ちて重みが変わり、あるいは NaN が出ます。**ランダムな入力で不変条件を掃く**のは、幾何アルゴリズムの検査として非常に有効です。

`CollinearSamplesDoNotCrash` は、**退化した入力**の検査です。一直線に並んだ点ではドロネー分割ができません（三角形の面積が 0）。この場合 `Triangulate` は三角形を 1 つも生成せず、`ComputeWeights` が線分への射影に落ちます。**壊れた入力で落ちないこと**が、この種のコードの品質です。

## 43.9　つまずきやすいところ

**特定の領域でアニメーションが消える／NaN が出る**
三角形分割に穴があります。`double` で外接円判定をしているか確認してください（43.3 節）。

**三角形の境界でカクつく**
重心座標の判定に余裕（`-1.0e-5f`）を持たせていますか。厳密に `>= 0` にすると、辺の上で三角形が見つからず、凸包外の経路に落ちます。

**斜め移動で足が滑る**
位相の同期をしていません（43.7 節、第 42 章）。

**サンプルを追加したのに反映されない**
`Triangulate()` を呼び忘れています。

**一直線に並んだサンプルで動かない**
`Triangulate` が三角形を生成できません。線分への射影にフォールバックする実装になっているか確認してください。

**凸包の外で重みが 0 になる**
`ProjectOntoNearestEdge` が呼ばれていません。三角形が見つからなかった場合のフォールバックを確認してください。

**サンプルが多いと分割が遅い**
本書の実装は O(n²) 以上です。セットアップ時に一度だけなので通常は問題になりませんが、数百点を扱うなら空間分割を導入してください。

## この章のまとめ

- 2D ブレンドスペースは、**パラメータ平面にクリップを配置**する。移動の向きと速さを同時に扱える。
- サンプルは格子状とは限らない（中心 + 円周 8 方向が典型）ので、**三角形分割 + 重心座標**が標準的な解法。
- 分割は**ボウヤー・ワトソン法**でドロネー三角形分割。**外接円の判定は `double`** で行う ―― `float` では分割が壊れる。セットアップ時に一度だけなので、コストは問題にならない。
- 重心座標は代数的な恒等式なので、**重みの合計は厳密に 1**。実測で `|Σw − 1| ≤ 2.38e-07`（20,000 点）。
- **凸包内での非ゼロ重みは 3 個以下。** サンプルが 100 個あっても、毎フレーム混ぜるのは 3 つ。
- **凸包の外は、最も近い辺に射影する。** 外側でも重みの合計は 1 に保たれ、アニメーションが消えない。
- 判定に**わずかな余裕**（`-1e-5`）を持たせる。厳密にすると辺の上で三角形が見つからない。
- **退化した入力（一直線、2 点、1 点）で落ちないこと**が品質。幾何アルゴリズムでは特に重要。
- 検査の型は「**ランダムな入力を大量に流して不変条件を掃く**」。三角形分割の穴は、これで確実に見つかる。
