# 育てるメモリアロケーター

## C++23 / Visual Studio で20行から始めるゲーム向けメモリ管理

---

## 本書の構造

読者は最初から最後まで**同じ1つのライブラリ**を育てます。各章は原則としてこの流れで進みます。

1. **今の困りごと** — 前章までのコードで何が足りないか
2. **今日足す1つの変更** — 追加する概念は章あたり1つだけ
3. **書いて動かす** — 実際にビルドして結果を見る
4. **わざと壊す** — 失敗するケースを自分で作って確認する
5. **計測する** — 変更前後を数字で比較する
6. **コラム** — 先人が同じ問題をどう解いたか(歴史)

コードは `v0.1` から `v1.0` まで、章ごとにバージョンを進めながら成長させます。
